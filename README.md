## 자동화가 움직이는 원칙 (`docs/역할구조.md`)

모든 자동화는 네 칸 중 하나에 속합니다.

| 칸 | 하는 일 | 예시 |
|---|---|---|
| ① 수집 | 숫자·문서를 가져와 기록만 | 조회수 스냅샷, 코인 시세, 채용공고 |
| ② 규칙 | 코드로 정한 규칙대로 판정·차단·복구 | 제목 검사, 손절선, 파일 변조 감시 가드 |
| ③ 분석 | AI가 데이터를 읽고 리포트·제안 작성 | 주간 회고, 자가감사 |
| ④ 실행 | 실제 업로드·(모의)매매·발행 | 쇼츠 업로드, 모의 매수·매도 |

- **분석 AI는 설정·코드를 직접 못 고칩니다.** 몰래 고치면 가드가 원래대로 되돌리고 폰으로 알립니다.
- **2026-09-21부터 "선조치 후보고"**: 되돌릴 수 있는 변경(유튜브 회고 전략, 대본 프롬프트 개선)은 승인을 기다리지 않고 코드가 자동 적용한 뒤 바탕화면 보고 파일과 폰 푸시로 알립니다. 이전본은 모두 보관돼 되돌릴 수 있습니다.
- **돈·정책·채널 정체성처럼 사람이 정해야 하는 것**은 리포트의 「주인이 고를 것」 절에 **A/B/C/D 선택지**(추천안·안 정하면 생기는 일 포함)로 올라오고, 주인은 "1A 2B"처럼 답하면 됩니다 (2026-09-28~, 유튜브 회고·코인 회고·자가감사 공통).

## 1. 🎬 1분호기심 — 유튜브 완전 자동화 (`yt-auto`)

심리학·뇌과학·행동경제학 렌즈로 풀어내는 지식 쇼츠 채널입니다. 사람이 손대지 않아도 매일 아침·저녁 쇼츠가 올라갑니다.

```
트렌드 수집 → 전략 엔진이 오늘 슬롯·계열 결정 → Claude가 오리지널 대본 + 사후검사
→ 음성·자막·AI 삽화를 ffmpeg로 렌더링 → YouTube API 업로드 → 밤마다 조회수 기록 → 일요일 회고로 전략 갱신
```

| 시각 | 하는 일 |
|---|---|
| 07:00 | 아침 쇼츠 (고전 심리실험형: 연도·연구자·숫자 훅) |
| 09:30 | 영어 채널 "1-Minute Wonder"에 한국 쇼츠 1편 현지화 업로드 |
| 17:20 | 저녁 영상 첫 장면용 AI 영상 클립 미리 생성 (실험 중) |
| 18:00 | 저녁 쇼츠 (생활 속 상황 + 대처 리스트형, 요일별로 생활심리·우주AI 계열) |
| 23:50 | 무결성 점검 → 조회수 스냅샷 → 댓글 자동 답글 → hub 적재 (일요일엔 주간 회고 + 프롬프트 점검 추가) |
| 10분마다 | 채널 조회수·구독자 샘플링 (대시보드 차트용) |

- 제목·의료 단어 검사, 같은 계열 연속 금지, 업로드 전 대본 채점 게이트를 **코드로 강제**
- 일요일 회고가 직전 전략을 스스로 채점하고, 팩트체크를 통과한 경우에만 새 전략이 자동 적용됨
- 올린 영상이 채널에서 사라지면 한 번 알림 (2026-09-21~)
- 실패·품질 저하 발행 시 바탕화면 경고 파일 + 폰 푸시

`archive/유튜브자동화_옛백업/` 은 2026-08-07 이전 OneDrive에서 돌던 옛 코드입니다. 실제 운영 코드는 `yt-auto` 저장소입니다.

집가는 모임에서 QR로 모여 미니게임을 하고, 점수가 낮으면 "집 가" 하고 카카오T를 열어주는 웹 서비스입니다.

| `uploader/` | 원클릭 업로더. `watch/`에 영상을 넣고 `업로드.bat` → 유튜브·인스타·쓰레드·네이버블로그·티스토리 |

## 5. 💬 market-compass — 카카오 마케팅 메시지 에이전트 (`market-compass`)

1인 셀러가 "지난달 안 온 단골한테 뭐 좀 보내줘"라고 말하면 대상 선정 → 문구 생성 → **정보통신망법·카카오 정책 위반을 코드로 검사** → 사람 승인 두 번 → (가상) 발송까지 하는 에이전트입니다. 핵심은 "자동"보다 **"안 걸리게"**.

- 모듈: **Radar**(대상 판단) / **Guard**(규제 규칙 R01~R12) / **Dispatch**(발송 요청서·실행)
- 원칙: 숫자는 코드만 계산, 실측과 추정 분리, 발송 경로는 한 곳뿐
- 진행: 0일차 기획·1일차 가상 데이터·2일차 Guard 규칙 절반(테스트 24/48) 완료. 일차마다 비개발자용 학습노트 작성

## 다른 PC에서 세팅

1. 저장소들을 클론 (가능하면 메인 PC와 같은 경로: `D:\yt-auto`, `D:\ai-daily`, `D:\coin-bot`, `D:\market-compass`)
2. 파이썬 3.12 설치 → 각 폴더에서 `python -m venv .venv` → `.venv\Scripts\pip install -r requirements.txt`
3. 비밀 파일(`secrets/`, 토큰, `uploader/config.json`, 알림 설정)은 깃에 없으니 메인 PC에서 직접 복사
4. **자동 실행(작업 스케줄러)은 메인 PC에서만.** 두 PC에서 같이 돌리면 이중 업로드·이중 매매가 납니다. 다른 PC는 코드 수정·분석·대시보드 열람용입니다.

## 공통 규칙

- 토큰·비밀 파일·영상 결과물·BGM은 커밋하지 않음 (`.gitignore` 참고). 이 저장소는 공개라 메모리 사본도 비밀정보를 지운 뒤 올림
- `.bat` / `.ps1` 파일에는 한글·이모지 금지 (CP949 깨짐으로 실행 실패한 전례 있음)
- 유튜브·쇼츠 등 자동재생 페이지는 브라우저로 열지 않고 API로만 상태 확인
- 이상 징후를 발견하면 주인이 묻기 전에 먼저 보고
