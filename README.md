## 1. 🎬 1분호기심 — 유튜브 완전 자동화 (`yt-auto`)

심리학·뇌과학·행동경제학 렌즈로 트렌드를 풀어내는 지식 쇼츠 채널입니다.
사람이 손대지 않아도 매일 아침 7시와 저녁에 쇼츠가 올라갑니다.

**파이프라인**

```
유튜브 급상승 트렌드 수집 → Claude가 오리지널 대본 작성 → edge-tts 내레이션 + 자막 + 배경을 ffmpeg로 렌더링
→ YouTube Data API로 업로드 (제목·설명·태그·재생목록·썸네일까지) → 매일 조회수 스냅샷 → 주간 회고로 전략 자동 수정
```

**핵심 기능**
- 아침 슬롯은 고전 실험형(연도·연구자·숫자 훅), 저녁 슬롯은 2인칭 자기진단형으로 코드에서 강제
- 4개 계열(고전실험 / 생활심리 / 트렌드 / 우주·AI) 재생목록 자동 분류, 연속 같은 계열 금지
- 의료 단어·모호 제목 정규식 사후검사 → 위반 시 1회 재생성, 또 위반이면 예비 대본 사용
- 매주 회고 에이전트가 직전 플레이북을 스스로 채점해 전략 파일(`data/strategy.json`) 갱신
- 모바일 대시보드(아티팩트)에 조회수·구독자·AX·코인 탭 통합 표시
- 실패 시 폰 푸시 알림 (`D:\notify`, 깃에 없음)

**실행**: `D:\yt-auto` 에서 `python -m src.pipeline` (작업 스케줄러가 자동 호출)

이 저장소의 `archive/유튜브자동화_옛백업/` 은 2026-08-07 이전 OneDrive에서 돌던 옛 코드의 백업본입니다. 실제 운영 코드는 `yt-auto` 저장소입니다.

## 2. 🏠 집가(ZipGa) 마케팅 자동화 (`zipga-marketing/`)

집가는 모임에서 QR로 모여 미니게임을 하고, 점수가 낮으면 "집 가" 하고 카카오T를 열어주는 웹 서비스입니다.
6인 팀 프로젝트의 마케팅 파트를 혼자 자동화한 것입니다. 사이트: https://zip-ga-frontend.vercel.app/

**폴더 구성**

| 폴더 | 역할 |
|---|---|
| `m1_input/` ~ `m6_queue/`, `run.py` | M1~M6 파이프라인: 영상 정규화 → 전사 → 9:16 클립 → 문구 생성 → 스토어 링크 → 발행 큐 |
| `comfy/` | ComfyUI Desktop 자동 연결. `scenes.txt`에 장면을 적고 bat 더블클릭 → 로컬 GPU로 영상·BGM 생성 |
| `teaser/` | 앱 녹화 화면을 폰 프레임에 합성한 티저·시연 영상, 채널 배너·커버 제작 스크립트 |
| `uploader/` | 원클릭 업로더. `watch/`에 영상을 넣고 `업로드.bat` → 유튜브·인스타·쓰레드·네이버블로그·티스토리 |
| `content/` | 출시 전 영상 15편 기획(`기획.json`) → ComfyUI 프롬프트·채널별 문구 자동 생성 |
| `.claude/skills/` | 코워크 스킬 9종 (일일 브리프, 경쟁사 감시, 시장 트렌드, ASO, 글쓰기, 발행) |
| `reports/` | 채널별 조회수·팔로워 추적 HTML 리포트 (`리포트.bat`) |
| `docs/` | 결정 기록, 조사 기록, 에러 기록 |
| `accounts/`, `prompts/`, `context/` | 계정별 페르소나, 문구 톤, 스킬 공통 설정 |

**발행 현황 (2026-09 기준)**
- 유튜브 채널 "난 집이 좋더라": 티저 + 시연 쇼츠 4편 예약 발행
- 쓰레드: API 자동 발행 연결 완료, 작업 스케줄러로 예약 게시
- 인스타: 수동 업로드 (API는 Meta 검수 대기)

**원칙**: 플랫폼 제재 예방을 위해 공개 문구·영상에서 술·음주 관련 표현과 장면을 전면 금지합니다. "모임", "늦은 밤"으로 표현합니다.

## 4. 🪙 코인 모의투자 봇 (`coin-bot`)

거래소 계좌 없이 가상 자금 1,000만 원으로 매매 전략을 검증하는 봇입니다. 표준 라이브러리만 사용합니다.

- **10분 사이클**: 업비트 공개 API 시세 + 뉴스 RSS·공포탐욕지수 → 5분봉 EMA·RSI·변동성돌파 전략으로 매수·청산
- **안전장치**: 손절 -2% / 익절 +3% / 트레일링 / 1회 10% / 최대 3종목 / 하루 -3% 한도 / BTC 급락 가드 / `STOP.txt`로 신규매수 중지
- **매일 07:10 리포트**, **매주 일요일 21:30 주간 회고** (헤드리스 클로드가 성과를 분석해 설정 변경을 제안만 함)
- 모든 매매에 한글로 근거 기록. 대시보드 🪙 탭에서 자산 곡선 확인
- 실전 전환은 몇 주 검증 후 별도 결정

## 5. 🐱 몽글이 — 버추얼 스트리머 (`vtuber/`)

브라우저(HTML + MediaPipe)만으로 동작하는 주황 고양이 캐릭터입니다. 별도 프로그램 설치가 없습니다.

- 고개·눈·입·눈썹·미소·손 추적, 캠 앞에서 사라지면 2.5초 뒤 수면 모드(Zzz + 자리비움 팻말)
- 초록 크로마키 배경 → OBS 윈도우 캡처 → 숲(SOOP)·치지직 송출
- 실행: `몽글이 시작.bat` → http://localhost:8977 (`?demo=1`은 카메라 없이 확인)
- 단축키: H(UI 숨김), P(캠 미리보기), 1~4(배경색)
- 자세한 사용법: [vtuber/사용설명서.md](vtuber/사용설명서.md)

## 다른 PC에서 세팅

1. 4개 저장소를 클론 (가능하면 메인 PC와 같은 경로: `D:\yt-auto`, `D:\ai-daily`, `D:\coin-bot`)
2. 파이썬 3.12 설치 → 각 폴더에서 `python -m venv .venv` → `.venv\Scripts\pip install -r requirements.txt`
3. 비밀 파일(`secrets/`, 토큰, `uploader/config.json`)은 깃에 없으니 메인 PC에서 직접 복사
4. **자동 실행(작업 스케줄러)은 메인 PC에서만.** 두 PC에서 같이 돌리면 이중 업로드·이중 매매가 납니다.

## 공통 규칙

- 토큰·비밀 파일·영상 결과물·BGM은 커밋하지 않음 (`.gitignore` 참고)
- `.bat` / `.ps1` 파일에는 한글·이모지 금지 (CP949 깨짐으로 실행 실패한 전례 있음)
- 유튜브·쇼츠 등 자동재생 페이지는 브라우저로 열지 않고 API로만 상태 확인
