## 한 일

**영상 하나 만들면 여러 채널에 자동으로 나가는 파이프라인**을 만들고, 실제로 발행까지 돌렸습니다.

### 만든 도구 3개 (전부 더블클릭 실행)

| 도구 | 하는 일 |
|---|---|
| `영상만들기.bat` | AI로 홍보 영상 생성 |
| `업로드.bat` | 5개 채널에 업로드 (채널별 개별 실행도 가능) |
| `리포트.bat` | 채널별 성과 수집해 리포트 생성 |

### 만든 콘텐츠

- 티저 영상 **4편** (15초·30초, 실사·애니 버전)
- 유튜브 썸네일 / 채널 배너 / 인스타 릴스 커버 / 영상 워터마크
- 채널별 문구 세트 (채널마다 다른 글)

## 기술적으로 해결한 것

**AI로는 앱 화면을 만들 수 없었습니다.** 한글이 전부 깨져서요.

→ 역할을 나눴습니다. **배경만 AI로 생성**하고, **화면 안에는 실제 앱 녹화를 합성**했습니다. 폰 프레임과 자막은 코드로 만들었습니다.

결과적으로 진짜 앱 홍보 영상처럼 보이면서, 화면 내용은 100% 실제입니다.
