# 콤피 자동 연결 — 사용법

콤피(ComfyUI)를 껐다 켜도, 아예 안 켜져 있어도 **알아서 연결해서 영상을 만듭니다.**
콤피 화면을 열어 프롬프트를 붙여넣을 필요가 없어요.

---

## 파일 3개만 알면 됩니다

| 파일 | 언제 쓰나 |
|---|---|
| **`영상만들기.bat`** | 영상 만들 때 (고화질) — 제일 자주 쓸 것 |
| **`영상만들기_빠른초안.bat`** | 느낌만 빨리 보고 싶을 때 (화질 낮음, 3배 빠름) |
| **`scenes.txt`** | 어떤 장면을 만들지 적는 곳 (메모장으로 열어서 수정) |

`콤피켜기.bat` 은 콤피 서버만 켜고 싶을 때 씁니다 (보통은 안 써도 됩니다).

---

## 쓰는 법

1. **`scenes.txt` 를 메모장으로 열어** 만들고 싶은 장면을 한 줄에 하나씩 적습니다
   - `#` 으로 시작하는 줄은 무시됩니다 (메모용)
   - 지금은 "순화 30초" 영상의 6장면이 들어 있습니다
2. **`영상만들기.bat` 더블클릭**
3. 기다리기 — 장면마다 진행 상황이 표시됩니다
4. 완성되면 `uploader\watch\새영상.mp4` 로 저장됩니다
5. **`업로드.bat`** 으로 올리면 끝

---

## 알아서 해주는 것들

| 상황 | 어떻게 되나 |
|---|---|
| 콤피가 꺼져 있음 | **자동으로 켭니다** (45초~3분) |
| 콤피 화면을 안 열어둠 | 상관없음 — 화면 없이 돌아갑니다 |
| 생성이 한 번 실패 | **30초 뒤 자동으로 재시도** (최대 3번) |
| 여러 장면 | 순서대로 만든 뒤 **한 편으로 자동으로 이어붙임** |
| 글자 깨짐 | 화면에 글자가 안 나오게 자동으로 처리 |

---

## 장면 쓰는 요령

영어로 쓰는 게 결과가 훨씬 좋습니다. 이 순서로 적으면 됩니다:

```
[스타일] + [장소·시간] + [누가 무엇을] + [카메라] + [분위기]
```

**예시**
```
Photorealistic cinematic vertical video. A quiet Seoul street at night,
an orange Korean taxi pulls up to the curb, a young man gets in,
gentle camera pull-back, warm neon reflections, film grain.
```

**자주 쓰는 표현**
| 원하는 것 | 넣을 말 |
|---|---|
| 실사 느낌 | `Photorealistic cinematic, film grain` |
| 애니메이션 느낌 | `Warm 3D animation style, Pixar-like cartoon` |
| 한국 배경 | `in Seoul, Korean street, Korean restaurant` |
| 술 안 나오게 | `No alcohol, no bottles, no drinks` |
| 카메라 움직임 | `slow push-in` / `gentle camera pull-back` / `handheld` |

> 글자 깨짐 방지 문구는 프로그램이 **자동으로** 붙이니 안 적어도 됩니다.

---

## 명령어로 더 세밀하게 (선택)

검은 창(터미널)에서 이렇게도 쓸 수 있습니다.

```bash
python comfy.py --scenes scenes.txt --out 광고.mp4 --mp 1.0 --sec 5
```

| 옵션 | 뜻 | 기본값 |
|---|---|---|
| `--scenes` | 장면 파일 | scenes.txt |
| `--prompt` | 장면 하나만 바로 생성 | — |
| `--out` | 결과 파일 이름 | 새영상.mp4 |
| `--mp` | 화질 (0.4 = 초안, 1.0 = 고화질) | 1.0 |
| `--sec` | 장면당 길이(초) | 5 |
| `--draft` | 빠른 초안 모드 | — |
| `--check` | 서버만 켜기 | — |

---

## 시간과 비용

| 화질 | 크기 | 장면당 시간 | 6장면 |
|---|---|---|---|
| 초안 (`--draft`) | 480×864 | 약 3분 | 약 20분 |
| 고화질 (기본) | 768×1376 | 약 12분 | 약 70분 |

**돈은 안 듭니다.** 내 그래픽카드(RTX 4080)가 직접 계산하는 거라 전기값 말고는 비용이 없어요.
AI 사용료(토큰)도 들지 않습니다. 몇 번이든 다시 뽑아도 됩니다.

> 여러 버전을 비교할 땐 **초안으로 빠르게** 뽑고, 발행할 것만 고화질로 다시 뽑는 게 효율적입니다.

---

## 잘 안 될 때

| 증상 | 해결 |
|---|---|
| "설치 위치를 못 찾음" | Comfy Desktop 을 한 번 실행했다가 끄고 다시 시도 |
| 계속 실패함 | `server.log` 파일을 열어 마지막 줄 확인 |
| 너무 느림 | `영상만들기_빠른초안.bat` 사용 · 다른 무거운 프로그램(에뮬레이터 등) 종료 |
| 결과가 이상함 | scenes.txt 의 문장을 더 구체적으로 · 여러 번 돌려서 고르기 (8개 중 3개 건지면 성공) |
