# 인스타그램 올리는 법 (오늘, 휴대폰으로)

> 인스타는 웹 자동화가 막혀 있어서 **휴대폰 앱으로 올리는 게 가장 안전하고 빠릅니다.**
> 다음 주에 API를 연결하면 그때부터는 `2_인스타만.bat` 한 번으로 자동이 됩니다.

---

## 0. 순서 요약

```
① 프로필 세팅 (링크·소개)  ← 제일 중요, 5분
② 릴스 업로드              ← 3분
③ 첫 댓글 달기             ← 30초
④ 스토리 올리기 (선택)     ← 1분
```

**①번을 먼저 하세요.** 인스타는 캡션에 링크를 써도 **눌리지 않습니다.**
프로필 링크가 사실상 유일한 통로예요.

---

## ① 프로필 세팅 (제일 중요)

인스타 앱 → 내 프로필 → **프로필 편집**

**소개(bio)** — `2_프로필_소개.txt` 내용을 붙여넣기
```
모임에서 하는 미니게임, 점수 낮으면 집 가
설치 없이 링크로 바로 👇
```

**링크** — "링크 추가" 눌러서
```
https://zip-ga-frontend.vercel.app/
```
제목은 `집가 바로 하기` 정도로.

**프로필 사진** — 바탕화면의 `zipga_icon.png` 사용

> 계정이 **프로페셔널(비즈니스/크리에이터)** 이 아니면 지금 전환해두세요.
> 설정 → 계정 → 프로페셔널 계정으로 전환. 다음 주 API 연결에 **필수**입니다.

---

## ② 릴스 업로드

**올릴 파일** (컴퓨터에서 휴대폰으로 옮기세요 — 카톡 나에게 보내기가 제일 빠름)

| 무엇 | 어디에 있나 |
|---|---|
| 영상 | `uploader\watch\21_유튜브_티저_15초_링크.mp4` |
| 커버 | `teaser\assets\ig_cover.jpg` |
| 캡션 | `instagram\1_릴스_캡션.txt` |

**순서**
1. 인스타 앱 → 하단 **+** → **릴스**
2. 영상 선택 (9:16이라 그대로 맞습니다)
3. **커버** → "갤러리에서 선택" → `ig_cover.jpg`
4. 캡션 칸에 `1_릴스_캡션.txt` 내용 붙여넣기
   - **`(@아이디)` 부분을 실제 인스타 아이디로 바꾸세요**
5. **"Facebook에도 공유" 끄기** (계정 연결 전이면)
6. 공유

> **음악은 넣지 마세요.** 영상에 이미 게임 소리가 들어 있고,
> 인스타 음원을 얹으면 나중에 다른 채널에 재사용할 때 저작권 문제가 생깁니다.

---

## ③ 첫 댓글 달기

올린 직후 본인 계정으로 댓글 하나 — `4_첫댓글.txt`

```
바로 해보실 분들은 프로필 링크 눌러주세요
https://zip-ga-frontend.vercel.app/

이상한 점 있으면 편하게 알려주세요!
```

댓글의 링크도 안 눌리지만, **주소를 눈에 보이게 남겨두면** 복사해서 들어오는 사람이 생깁니다.

---

## ④ 스토리 (선택)

릴스를 스토리로 공유 → `3_스토리_문구.txt` 문구를 텍스트로 얹고
**링크 스티커**에 사이트 주소를 넣으세요. **스토리 링크는 눌립니다.**

---

## 오늘 하면 안 되는 것

| 금지 | 이유 |
|---|---|
| 팀원 계정끼리 좋아요·팔로우 | 인기 조작으로 판정되면 전 계정 위험 |
| 같은 영상을 여러 계정에 올리기 | 영상 지문으로 감지됨 |
| 만든 지 얼마 안 된 계정으로 대량 활동 | 스팸 신호 |
| 유튜브와 똑같은 캡션 복붙 | 채널별로 다른 글이 원칙 (캡션은 이미 다르게 써뒀습니다) |

## 다음 주 — 자동화로 전환

1. 인스타를 **프로페셔널 계정**으로 전환 + 페이스북 페이지 연결
2. `uploader\마케팅자동화 설명서.md` **4장** 따라 메타 앱 연결
   - 아까 겪은 "개발자 역할 권한이 부족합니다" 오류 해결법이 4-3장에 있습니다
3. `config.json` 의 인스타 `enabled` 를 `true` 로
4. 이후로는 `2_인스타만.bat` 더블클릭이면 끝

> 앱 검수는 시간이 걸리니 **이번 주에 신청만 걸어두세요.**
