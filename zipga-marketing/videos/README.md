# videos

콤피로 만든 영상을 이 폴더에 넣으면 배포 대상이 됩니다.

## 파일명 규칙

파일명이 콘텐츠 파악의 기준이 됩니다. 날짜와 내용을 담아 저장하세요.

```
20260828_게임화면_1차.mp4
20260901_카카오T연동_데모.mp4
```

내용을 더 정확히 전달하고 싶으면 같은 이름의 메모 파일을 옆에 두세요.

```
20260828_게임화면_1차.mp4
20260828_게임화면_1차.txt      ← 이 영상이 뭘 보여주는지 몇 줄
```

메모가 없고 파일명으로도 내용을 알 수 없으면 **배포가 보류됩니다.** 추측한 설명을 붙여 올리지 않기 위해서입니다.

## 업로드 후

올린 영상은 `videos/uploaded/`로 자동으로 옮겨집니다. 이게 중복 업로드를 막는 장치이므로 직접 되돌리지 마세요.

기록은 `videos/uploaded/upload-log.md`에 쌓입니다.

## 인증 파일

구글 OAuth 클라이언트(`client_secret.json`)를 이 폴더에 둡니다. 최초 인증 후 `token.json`이 자동 생성됩니다.

둘 다 `.gitignore`에 들어 있습니다. **커밋하지 마세요.**
