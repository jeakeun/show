## 1. 한 문장 요약

**영상 하나를 만들면 여러 채널에 자동으로 나가는 파이프라인을 만들고, 실제로 3개 채널에 발행해 조회수 324회를 얻었습니다.**

---

## 2. 무엇을 만들었나

### 2-1. 세 덩어리로 나눠 만들었습니다

| | 하는 일 | 실행 방법 |
|---|---|---|
| ① **영상 생성** | AI로 홍보 영상 자동 생성 | `영상만들기.bat` |
| ② **발행** | 5개 채널에 업로드 | `업로드.bat` |
| ③ **리포트** | 채널별 성과 수집 | `리포트.bat` |

**전부 더블클릭 한 번**으로 동작합니다. 개발을 모르는 팀원도 쓸 수 있게 만드는 것이 목표였습니다.

### 2-2. 콘텐츠 파이프라인 (M1~M6)

```
영상 정규화 → 전사·자막 → 세로 클립 → 문구 생성 → 링크 생성 → 발행 큐
```

6명이 서로 기다리지 않고 동시에 작업할 수 있도록, **모듈 사이에 오가는 파일 형식만 고정**하고 내부 구현은 각자 자유롭게 했습니다.

> **@bbyagu.kbo**
> "집에 가고 싶은 사람이 일부러 못 치면 어떻게 되나요 ㅋㅋ"

**이 질문이 중요한 이유**

- 광고 없이 올린 첫 글에 **실제 사용 상황을 상상한 질문**이 왔습니다
- 우리 설계에 이미 답이 있습니다 — **"집에 갈래" 버튼**(자발적 귀가)
- 즉, **사용자가 우리가 설계한 시나리오를 스스로 떠올렸다**는 뜻입니다

## 5. 기술적으로 해결한 문제

### 5-1. AI로는 앱 화면을 만들 수 없었다

**문제** — AI 영상 생성 모델이 한글을 제대로 못 그려서, 앱 화면을 만들면 글자가 다 깨졌습니다.

**해결** — 역할을 나눴습니다.
- **배경**만 AI로 생성 (흐린 조명·분위기 컷)
- **화면 안**에는 실제 앱 녹화를 합성
- 폰 프레임과 자막은 코드로 생성

**결과** — 진짜 앱 홍보 영상처럼 보이면서, 화면 내용은 100% 실제입니다.

### 5-2. 플랫폼마다 제약이 전부 달랐다

조사해서 문서로 남긴 것 (출처 포함):

| 채널 | 확인한 제약 |
|---|---|
| 유튜브 | 감사 통과 전에는 API 업로드분이 **비공개로 잠김** |
| 인스타 | **로컬 파일 직접 업로드 가능** (resumable upload) — 별도 저장소 불필요 |
| 쓰레드 | 링크는 클릭됨. 단 **영상은 공개 URL 필요**, 500자 제한, DM 기능 없음 |
| 티스토리 | **Open API 종료** — 인터넷의 자동 포스팅 코드는 전부 동작하지 않음 |

> 이 조사가 없었으면 **불필요한 클라우드 저장소 비용**을 쓸 뻔했고,
> **동작하지 않는 티스토리 코드**에 시간을 버릴 뻔했습니다.

### 5-3. 신규 계정의 벽

새로 만든 유튜브 채널은 **설명란 링크가 클릭되지 않고 댓글 고정도 안 됩니다.**
전화번호 인증으로 해제했고, 그동안은 **댓글에 링크를 남기는 방식**으로 우회했습니다.

## 6. 제품 설계에서 의도적으로 뺀 것

발표에서 반드시 나올 질문에 대한 우리 입장입니다.

### "취했는지 판정하지 않습니다"

앱은 음주 상태를 **측정하거나 진단하지 않습니다.** 게임 점수만 보여주고, 40점 미만이면 귀가를 권할 뿐입니다.

**왜 뺐나**
- 점수로 취기를 판정해 표시하는 순간, 음주측정기·의료기기로 **오인될 소지**가 생깁니다
- 오판별 시 책임 소재 문제가 따라옵니다
- 학생 팀이 감당할 리스크가 아니라고 판단했습니다

**따라온 결과**
- 법적 리스크의 대부분이 해소됐습니다
- 이 앱은 측정 도구가 아니라 **모임용 게임**이 됐고, 마케팅 문구도 전부 그 기준으로 통일했습니다
- 공개 콘텐츠에서 **술·음주·취함 관련 표현과 장면을 전부 뺐습니다** (플랫폼 제재 예방)

### 그 외 뺀 것
- 귀가 상태 공유·보호자 알림 (프라이버시 부담)
- 목적지 자동 입력 (택시 앱 실행까지가 범위)

## 9. 예상 질문과 답변

**Q. 조회수 324회면 적은 것 아닌가요?**
A. 팔로워 0명, 광고비 0원, 발행 당일 기준입니다. 중요한 건 숫자보다 **파이프라인이 실제로 작동했다는 것**과 **모르는 사용자에게 제품 질문을 받았다는 것**입니다.

**Q. AI로 영상을 만들었다는데 품질은요?**
A. AI는 배경만 만들었고, **앱 화면은 전부 실제 녹화**입니다. AI가 한글을 못 그린다는 한계를 확인하고 역할을 나눈 결과입니다.

**Q. 왜 티스토리는 자동화를 안 했나요?**
A. 티스토리가 Open API를 종료해서 **기술적으로 불가능**합니다. 공식 공지를 확인했고, 브라우저 자동화는 안정성이 낮아 보조 수단으로만 두었습니다.

**Q. 음주 측정 정확도는 어떻게 되나요?**
A. **저희는 측정하지 않습니다.** 게임 점수를 보여주고 귀가를 권할 뿐입니다. 측정·진단으로 오인될 여지를 설계 단계에서 의도적으로 제거했습니다.

**Q. 40점은 어떻게 정했나요?**
A. **아직 근거 자료가 없습니다.** 실제 플레이 데이터를 모아 조정할 계획입니다. 반응속도 저하 연구를 참고할 수 있지만, "우리 앱이 정확하다"는 주장에는 쓰지 않을 생각입니다.
