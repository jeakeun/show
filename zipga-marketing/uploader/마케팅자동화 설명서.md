# 마케팅 자동화 설명서

> 이 문서는 **처음 하시는 분**을 기준으로 썼습니다. 개발을 몰라도 순서대로 따라 하면 됩니다.
> 모르는 단어가 나오면 맨 아래 **[용어 사전](#용어-사전)** 을 보세요.

---

## 전체 지도 — 어떤 파일이 뭘 하나요

이 프로젝트에는 도구가 세 종류 있습니다. **이 설명서는 ②번(발행)을 다룹니다.**

| | 하는 일 | 어디 | 설명서 |
|---|---|---|---|
| ① **영상 만들기** | AI로 영상 생성 | `comfy\영상만들기.bat` | `comfy\콤피 사용법.md` |
| ② **발행하기** | 유튜브·인스타·쓰레드 업로드 | `uploader\업로드.bat` | **이 문서** |
| ③ **리서치·다채널** | 경쟁조사·네이버·티스토리 | 클로드에게 말로 요청 | `README.md` |

**가장 흔한 흐름**

```
comfy\영상만들기.bat   (또는 직접 편집한 영상)
        ↓
uploader\watch 폴더에 영상이 들어옴
        ↓
uploader\업로드.bat    → 유튜브·인스타·쓰레드
```

---

## 0. 이게 뭔가요?

영상을 폴더에 넣고 **파일 하나만 더블클릭하면** 유튜브·인스타그램·쓰레드에 올라가게 하는 도구입니다.

```
영상을 watch 폴더에 넣는다  →  업로드.bat 더블클릭  →  끝
```

### 두 가지 모드가 있습니다

| 모드 | 설명 | 준비물 |
|---|---|---|
| **보조 모드** (지금 상태) | 업로드 페이지가 자동으로 열리고, 문구가 복사되고, 파일이 선택된 상태가 됨 → **드래그 한 번 + 붙여넣기 한 번** | 없음. 바로 사용 가능 |
| **완전 자동 모드** | 진짜로 알아서 다 올라감 | 플랫폼 연결 필요 (아래 3~5장) |

**처음에는 보조 모드로 시작하세요.** 이것만으로도 시간이 많이 줄어듭니다.
익숙해지면 3~5장을 보고 하나씩 연결하면 됩니다.

## 1. 매일 쓰는 방법

### 1-0. 어떤 버튼을 누를까

`uploader` 폴더에 실행 파일이 여러 개 있습니다. **한 채널만 올리고 싶을 때**를 위해 나눠뒀습니다.

| 파일 | 무엇을 하나 |
|---|---|
| **`업로드.bat`** | 5개 채널 전부 (유튜브·인스타·쓰레드·네이버블로그·티스토리) |
| `1_유튜브만.bat` | 유튜브에만 |
| `2_인스타만.bat` | 인스타그램에만 |
| `3_쓰레드만.bat` | 쓰레드에만 |
| `4_네이버블로그만.bat` | 네이버 블로그에만 |
| `5_티스토리만.bat` | 티스토리에만 |

**언제 채널별로 쓰나요**
- 한 채널만 실패해서 **거기만 다시** 올릴 때
- 채널마다 **다른 날에 나눠서** 올릴 때 (같은 날 몰아 올리면 스팸 신호가 됩니다)
- 아직 연결 안 된 채널은 건너뛰고 **연결된 것만** 돌릴 때

> **중요** — 채널별 버튼으로 올리면 영상이 `watch` 폴더에 **그대로 남습니다.**
> 다른 채널에도 올려야 하니까요. `업로드.bat`(전체)으로 돌렸을 때만 `uploaded` 폴더로 옮겨집니다.

### 1-1. 가장 단순한 경우

1. **영상을 준비합니다** (편집 프로그램에서 만든 mp4)
2. **`uploader\watch` 폴더에 넣습니다**
3. **`업로드.bat` 을 더블클릭합니다**
4. 검은 창이 뜨고, 플랫폼마다 순서대로 진행됩니다
5. 다 끝나면 영상이 `uploaded` 폴더로 옮겨집니다 (다시 올라가지 않게)

### 1-2. 문구를 직접 정하고 싶을 때

영상과 **같은 이름의 txt 파일**을 옆에 두면 그 내용이 캡션·설명란·글이 됩니다.

```
watch\
├─ 집가_티저.mp4
└─ 집가_티저.txt   ← 이 파일 내용이 문구가 됨
```

txt 파일이 없으면 미리 정해둔 기본 문구가 쓰입니다.

> **txt 파일 만드는 법**: 메모장을 열고 → 내용을 쓰고 → 저장할 때 **파일 이름을 영상과 똑같이**,
> 인코딩은 **UTF-8** 로 선택하세요. (인코딩을 안 바꾸면 한글이 깨질 수 있습니다)

### 1-2-1. 채널마다 다른 글을 쓸 때 (권장)

**같은 글을 여러 채널에 복붙하면 손해입니다.** 카페는 스팸으로 보고, 블로그·티스토리는
검색엔진이 중복으로 처리해 양쪽 다 손해예요. 그래서 채널별 문구를 따로 둘 수 있게 했습니다.

파일 이름 뒤에 **채널 이름**을 붙이면 됩니다.

```
watch\
├─ 티저.mp4
├─ 티저.youtube.txt      ← 유튜브용 (제목 + 설명 + 타임스탬프)
├─ 티저.instagram.txt    ← 인스타용 (짧고 이모지)
├─ 티저.threads.txt      ← 쓰레드용 (대화체, 500자 이내)
└─ 티저.txt              ← 위에 없는 채널이 쓸 공용 문구
```

쓸 수 있는 채널 이름: `youtube` · `instagram` · `threads` · `naver_blog` · `tistory`

**찾는 순서** — ① 채널 전용 → ② 공용(`티저.txt`) → ③ `config.json` 기본 문구
실행하면 어느 문구를 썼는지 화면에 표시되니 확인하고 올리면 됩니다.

### 1-3. 보조 모드에서 실제로 하는 일

`업로드.bat` 을 누르면 플랫폼마다 이렇게 진행됩니다.

1. 브라우저에 **업로드 페이지가 자동으로 열립니다**
2. **문구는 이미 복사돼 있습니다** (클립보드에)
3. **탐색기에 영상 파일이 선택된 채로 열립니다**
4. 당신이 할 일 두 가지:
   - 탐색기의 영상을 브라우저 페이지로 **드래그**
   - 문구 칸을 클릭하고 **Ctrl + V**
5. 다 올렸으면 검은 창에서 **엔터** → 다음 플랫폼으로 넘어갑니다
6. 세 개 다 끝나면 `이 영상 처리가 끝났나요?` 라고 물어봅니다 → **y** 입력

### 1-4. AI로 영상을 만들어서 올리는 경우

**방법 A — 클로드가 자동으로 (권장)**

`comfy` 폴더의 도구가 콤피를 알아서 켜고 영상까지 만들어 `watch` 폴더에 넣어줍니다.

1. `comfy\scenes.txt` 를 메모장으로 열어 원하는 장면을 한 줄에 하나씩 적기
2. **`comfy\영상만들기.bat` 더블클릭** → 콤피가 꺼져 있으면 자동으로 켜고 생성
3. **`uploader\업로드.bat` 더블클릭**

콤피 화면을 열 필요도, 프롬프트를 붙여넣을 필요도 없습니다.
느낌만 빨리 보려면 `영상만들기_빠른초안.bat` (3배 빠름, 화질 낮음)을 쓰세요.
자세한 건 `comfy\콤피 사용법.md` 를 보세요.

**방법 B — 콤피에서 직접 만든 경우**

1. 콤피 화면에서 영상 생성
2. **`가져오기.bat` 더블클릭** → `watch` 폴더로 자동 복사 (webm 이면 mp4 로 변환)
3. **`업로드.bat` 더블클릭**

한 번 가져온 영상은 다시 안 가져오니 중복 걱정은 없습니다.

### 1-5. 앱 화면으로 티저 만들기

실제 앱 녹화를 폰 모양 틀에 넣어 홍보 영상을 만드는 도구가 `teaser` 폴더에 있습니다.

```
python build_teaser.py           30초 버전
python build_teaser.py --short   15초 버전
```

- 자막 문구를 바꾸려면 `teaser\build_assets.py` 의 문장을 고치고 `python build_assets.py` 실행
- 어느 장면을 쓸지 바꾸려면 `build_teaser.py` 의 `SEGMENTS` 에서 시작 초만 수정
- 결과물은 `watch` 폴더에 저장되므로 바로 `업로드.bat` 으로 올릴 수 있습니다

> AI로 앱 화면을 그리지 않는 이유: AI가 만든 화면은 한글이 깨져서 가짜 티가 납니다.
> 그래서 **배경만 AI로 만들고, 화면 안에는 진짜 녹화 영상**을 넣습니다.

## 2. 연결하기 전에 — 전체 그림

완전 자동으로 만들려면 각 플랫폼에 **"이 프로그램이 내 계정에 올려도 된다"** 고 허락해줘야 합니다.
그 허락증이 **토큰(token)** 입니다.

| 플랫폼 | 걸리는 시간 | 심사 필요? | 난이도 |
|---|---|---|---|
| 유튜브 | 약 20분 | 감사 신청 필요 (기다림) | 보통 |
| 인스타그램 | 약 40분 | 앱 검수 필요 (기다림) | 어려움 |
| 쓰레드 | 약 20분 | 없음 | 보통 |
| 네이버 블로그 | 약 30분 | API 사용 신청 | 보통 (발급 여부 미확인) |
| 티스토리 | — | — | **자동 불가** — 보조 모드만 |

> **티스토리는 자동 업로드가 안 됩니다.** 티스토리가 Open API를 종료했기 때문입니다.
> `5_티스토리만.bat` 은 글쓰기 페이지를 열고 문구를 복사해주는 데까지만 합니다.
> 인터넷에 돌아다니는 티스토리 자동 포스팅 코드는 지금은 동작하지 않으니 시도하지 마세요.

> **추천 순서**: 쓰레드(심사 없음) → 유튜브 → 인스타그램
> 유튜브·인스타는 심사를 기다려야 하니 **오늘 신청만 걸어두고** 나머지를 진행하세요.

### 미리 알아둘 두 가지

**① 심사를 통과하기 전에도 쓸 수 있습니다.**
유튜브는 비공개로 올려서 수동 공개, 인스타는 검수 전에도 본인 계정 테스트가 가능합니다.

**② 준비된 것만 켜면 됩니다.**
`config.json` 에서 `enabled` 를 `true` 로 바꾼 플랫폼만 자동으로 동작합니다.
나머지는 보조 모드로 알아서 넘어갑니다. 한꺼번에 다 할 필요가 없습니다.

## 3. 유튜브 연결하기 (약 20분)

### 3-1. 구글 클라우드에서 프로젝트 만들기

1. 브라우저에서 **https://console.cloud.google.com** 접속
2. **채널을 가지고 있는 구글 계정**으로 로그인
3. 화면 위쪽 가운데의 **프로젝트 선택** 버튼 클릭 → **새 프로젝트**
4. 이름에 `zipga-uploader` 입력 → **만들기**
5. 만들어지면 다시 위쪽에서 **그 프로젝트를 선택**합니다 (중요! 안 하면 다음 단계가 엉뚱한 데 적용됩니다)

### 3-2. 유튜브 기능 켜기

1. 왼쪽 메뉴 **API 및 서비스 → 라이브러리**
2. 검색창에 `YouTube Data API v3` 입력
3. 검색 결과 클릭 → **사용 설정** 버튼 클릭

### 3-3. 동의 화면 만들기

1. 왼쪽 메뉴 **API 및 서비스 → OAuth 동의 화면**
2. User Type: **외부** 선택 → 만들기
3. 앱 이름: `zipga-uploader`, 사용자 지원 이메일과 개발자 이메일: **본인 이메일**
4. 저장하고 계속 → 범위(Scopes) 화면은 그냥 **저장하고 계속**
5. **테스트 사용자** 화면에서 **+ ADD USERS** → **본인 구글 이메일 추가** ← **이거 빼먹으면 로그인 단계에서 막힙니다**
6. 저장하고 계속

### 3-4. 열쇠 파일 받기

1. 왼쪽 메뉴 **API 및 서비스 → 사용자 인증 정보**
2. 위쪽 **+ 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
3. 애플리케이션 유형: **데스크톱 앱** 선택 → 이름 아무거나 → **만들기**
4. 팝업이 뜨면 **JSON 다운로드** 클릭
5. 받은 파일 이름을 **`client_secret.json`** 으로 바꿉니다
6. 그 파일을 **`uploader\secrets\` 폴더** 안에 넣습니다

### 3-5. 설정 켜기

`uploader\config.json` 을 메모장으로 열고 유튜브 부분을 이렇게 바꿉니다.

```json
"youtube": {
  "enabled": true,
  "privacy": "private",
  "client_secret_file": "secrets/client_secret.json"
}
```

> 처음에는 `"privacy": "private"` 를 권합니다. 잘 올라가는지 확인한 뒤 `"public"` 으로 바꾸세요.

### 3-6. 첫 실행 (최초 1회만)

`업로드.bat` 을 실행하면 브라우저가 열립니다.
→ 구글 로그인 → **"안전하지 않음" 경고가 나오면 고급 → 계속 진행** → **허용**

이건 처음 한 번만 하면 되고, 다음부터는 자동으로 로그인됩니다.

### ⚠️ 유튜브에서 꼭 알아야 할 것

**심사(감사)를 안 받으면 올린 영상이 비공개로 잠깁니다.**
공개로 설정해도 유튜브가 다시 비공개로 되돌립니다. 이건 오류가 아니라 정책입니다.

**해결 방법 두 가지**
- **당장**: 비공개로 올린 뒤 유튜브 스튜디오에서 손으로 공개 전환 (클릭 2번)
- **근본**: 구글 클라우드 콘솔의 YouTube API 페이지에서 **감사(audit) 신청** → 통과하면 잠기지 않음

심사에 시간이 걸리니 **오늘 신청해두세요.**

## 4. 인스타그램 연결하기 (약 40분)

인스타가 제일 까다롭습니다. 순서대로 하세요.

### 4-0. 먼저 계정 조건 맞추기 (이거 안 하면 시작도 안 됩니다)

**① 프로페셔널 계정으로 전환**
인스타 앱 → 설정 → 계정 → **프로페셔널 계정으로 전환** → 크리에이터 또는 비즈니스 선택

**② 페이스북 페이지와 연결**
인스타 앱 → 설정 → **비즈니스 도구 및 관리 옵션 → 페이지 연결**
(페이스북 페이지가 없으면 페이스북에서 새로 하나 만드세요. 빈 페이지도 괜찮습니다)

### 4-1. 메타 개발자 앱 만들기

1. **https://developers.facebook.com** 접속 → 인스타와 연결된 페이스북 계정으로 로그인
2. 오른쪽 위 **내 앱** → **앱 만들기**
3. 사용 사례: **기타** → 다음
4. 앱 유형: **비즈니스** → 다음
5. 앱 이름 `zipga-uploader`, 연락처 이메일 입력 → **앱 만들기**

### 4-2. 인스타그램 기능 추가

앱 대시보드에서 **Instagram Graph API** 또는 **Instagram** 제품을 찾아 **설정** 클릭

### 4-3. 🔴 내 계정을 앱에 등록하기 (여기서 대부분 막힙니다)

> **"개발자 역할 권한이 부족합니다"** 오류가 나는 이유가 바로 이 단계를 안 해서입니다.

1. 앱 대시보드 왼쪽 메뉴 **앱 역할 → 역할**
2. **사람 추가** 클릭
3. **인스타그램 테스터** 를 선택하고 본인 인스타 계정 입력 → 초대 보내기
4. **여기가 핵심** — 초대는 **이메일이 아니라 인스타그램 앱 안에서** 수락합니다:

   **인스타 앱 → 설정 → 웹사이트 권한 → 앱 및 웹사이트 → 테스터 초대 → 수락**

5. 수락 후 **5~10분 기다립니다** (메타는 반영이 느립니다. 바로 하면 같은 오류가 납니다)

### 4-4. 토큰 만들기

> **먼저 알아둘 것 — 인스타 연동에는 길이 두 개 있습니다.**
> 이름이 비슷해서 헷갈리는데, **권한 이름이 서로 다릅니다.**
>
> | 방식 | 권한 이름 | 페이스북 페이지 |
> |---|---|---|
> | **페이스북 로그인** (이 설명서가 쓰는 방식) | `instagram_basic` 계열 | 필요 |
> | 인스타그램 로그인 (신형) | `instagram_business_...` 계열 | 불필요 |
>
> 화면에서 권한을 찾을 때 **`instagram_basic` 이 안 보이고 `instagram_business_basic` 만 보인다면**,
> 앱이 "인스타그램 로그인" 방식으로 만들어진 것입니다. 그때는 아래 3번 대신
> `instagram_business_basic` + `instagram_business_content_publish` 두 개를 고르세요.

1. 개발자 사이트 위쪽 메뉴 **도구 → 그래프 API 탐색기**
2. 오른쪽 **Meta 앱** 칸에서 **방금 만든 앱이 선택돼 있는지 확인** ← 다른 앱이면 오류납니다
3. **권한 추가**에서 아래를 찾아 체크합니다.

   **필수 (없으면 게시가 안 됩니다)**
   - `instagram_basic`
   - `instagram_content_publish`
   - `pages_read_engagement`

   **있으면 편한 것** (4-5에서 계정 번호를 찾을 때 씀)
   - `pages_show_list`

4. **Generate Access Token** 클릭 → 로그인 → 내 페이지와 인스타 계정 선택 → 허용
5. 길고 복잡한 글자가 나옵니다. 이게 **토큰**입니다. 복사해두세요.

> **게시가 계속 막히면 PPA를 확인하세요.**
> 페이스북 페이지에 **페이지 게시 승인(Page Publishing Authorization)** 이 걸려 있으면,
> 권한이 다 맞아도 게시가 차단됩니다. 페이지 설정에서 미리 인증을 끝내두세요.

### 4-5. 내 인스타 계정 번호 찾기

같은 그래프 API 탐색기 화면에서, 주소 입력칸에 아래를 그대로 넣고 **제출**:

```
me/accounts?fields=instagram_business_account,name
```

결과에서 `instagram_business_account` 안의 **`id` 숫자**가 필요한 값입니다. 복사해두세요.

### 4-6. 토큰을 60일짜리로 늘리기

방금 받은 토큰은 **1시간이면 만료**됩니다. 늘려야 합니다.

1. **https://developers.facebook.com/tools/debug/accesstoken** 접속
2. 토큰을 붙여넣고 **디버그** 클릭
3. 아래쪽 **장기 실행 액세스 토큰으로 연장** 버튼 클릭
4. 새로 나온 **긴 토큰**을 복사

### 4-7. 설정에 입력

`uploader\config.json` 의 인스타 부분:

```json
"instagram": {
  "enabled": true,
  "ig_user_id": "4-5에서 찾은 숫자",
  "access_token": "4-6에서 연장한 긴 토큰",
  "api_version": "v23.0",
  "share_to_feed": true
}
```

### ⚠️ 인스타에서 알아야 할 것

- **토큰은 60일마다 만료됩니다.** 만료되면 업로드가 실패하는데, **4-6번만 다시** 하면 됩니다
- 다른 사람에게도 보이게 하려면 **앱 검수(App Review)** 를 신청해야 합니다. 본인 계정 테스트는 검수 없이 됩니다
- **좋은 소식**: 인스타는 영상 파일을 컴퓨터에서 바로 올릴 수 있습니다. 별도 저장소(R2 등)가 필요 없습니다

## 5. 쓰레드 연결하기 (약 20분)

**쓰레드는 심사가 없어서 제일 빨리 됩니다. 여기부터 시작하는 걸 추천합니다.**

### 5-1. 쓰레드 전용 앱 만들기

> ⚠️ **인스타용 앱으로는 안 됩니다.** 쓰레드는 별도 앱이 필요합니다.

1. **https://developers.facebook.com** → **내 앱** → **앱 만들기**
2. 사용 사례에서 **Threads API** 선택 → 다음
3. 앱 이름 `zipga-threads` 입력 → 앱 만들기

### 5-2. 권한 추가

앱 대시보드에서 Threads 사용 사례 설정 → 권한에서 아래 두 개 추가:
- `threads_basic`
- `threads_content_publish`

### 5-3. 내 계정을 테스터로 등록

1. 왼쪽 메뉴 **앱 역할 → 역할** → **사람 추가** → **쓰레드 테스터** 로 본인 계정 초대
2. **수락은 쓰레드 앱에서**:

   **쓰레드 앱 → 설정 → 계정 → 웹사이트 권한 → 초대 수락**

3. 5~10분 기다립니다

### 5-4. 토큰 만들기

앱의 Threads 설정 화면에 있는 **토큰 생성(Generate Access Token)** 버튼 클릭 → 나온 토큰 복사

### 5-5. 설정에 입력

```json
"threads": {
  "enabled": true,
  "threads_user_id": "",
  "access_token": "5-4에서 받은 토큰"
}
```

`threads_user_id` 는 비워두면 프로그램이 자동으로 찾습니다.

### ⚠️ 쓰레드에서 알아야 할 것

- **글(텍스트)만 자동으로 올라갑니다.** 쓰레드 API는 영상을 인터넷에 공개된 주소로만 받기 때문입니다
- 영상까지 올리고 싶은 날은 **보조 모드**로 직접 올리세요
- 글자 수 **500자 제한** — 넘으면 게시가 실패합니다
- 쓰레드는 **DM 자동화 기능이 아예 없습니다.** 링크는 프로필에 걸거나 인스타로 유도하세요

## 6. 문제 해결

### 6-1. 자주 나오는 오류

| 증상 | 원인과 해결 |
|---|---|
| **"개발자 역할 권한이 부족합니다"** | 내 계정이 앱에 등록 안 됨 → **4-3** 또는 **5-3** 을 하세요. 이미 했다면 ① 인스타/쓰레드 **앱 안에서** 초대를 수락했는지 ② 5~10분 기다렸는지 ③ 그래프 API 탐색기에서 **맞는 앱**이 선택됐는지 확인 |
| 검은 창이 떴다가 바로 꺼짐 | `watch` 폴더에 영상이 없습니다. 영상을 넣고 다시 실행 |
| "라이브러리 미설치" | `uploader` 폴더의 `.deps_ok` 파일을 지우고 `업로드.bat` 다시 실행 |
| 유튜브 영상이 비공개로 잠김 | 정상입니다. **3장 마지막** 참고 — 감사 신청 또는 수동 공개 |
| 유튜브 로그인에서 "확인되지 않은 앱" | **3-3의 5번** 테스트 사용자에 본인 이메일을 추가했는지 확인 |
| 인스타 "토큰 만료" / 갑자기 실패 | 60일이 지났습니다. **4-6** 만 다시 하세요 |
| 인스타 "권한 오류" | 프로페셔널 계정인지, 페이스북 페이지와 연결됐는지 확인 (**4-0**) |
| 권한 목록에 `instagram_basic` 이 안 보임 | 앱이 '인스타그램 로그인' 방식입니다. `instagram_business_basic` + `instagram_business_content_publish` 를 고르세요 (**4-4** 안내 참고) |
| 권한은 다 줬는데 게시만 실패 | 페이지 게시 승인(PPA)이 안 끝났을 수 있습니다. 페이스북 페이지 설정에서 인증하세요 |
| 쓰레드 게시 실패 | 문구가 500자를 넘었는지 확인 |
| 한글 문구가 깨짐 | txt 파일을 메모장에서 **UTF-8** 로 저장하세요 |
| 같은 영상이 또 올라갈까 걱정 | 처리된 영상은 `uploaded` 폴더로 옮겨지므로 중복되지 않습니다 |

### 6-2. 무엇이 잘못됐는지 확인하는 법

- `uploads_log.csv` 를 엑셀로 열면 **언제 무엇을 어디에 올렸는지** 기록이 남아 있습니다
- 검은 창에 나오는 `[실패]` 뒤의 문장이 원인입니다. 그대로 검색하거나 물어보세요

## 7. 안전 수칙 (꼭 지켜주세요)

### 7-1. 절대 공유하면 안 되는 것

**`secrets` 폴더와 `config.json` 안의 토큰은 비밀번호와 같습니다.**

- 팀 단톡방에 올리지 마세요
- 깃허브에 올리지 마세요 (`.gitignore` 로 막아뒀지만 확인하세요)
- 화면 공유할 때 이 파일을 열어두지 마세요

토큰이 유출되면 **남이 내 계정에 마음대로 글을 올릴 수 있습니다.**

### 7-2. 계정을 지키는 규칙

| 하면 안 되는 것 | 왜 |
|---|---|
| 같은 영상 파일을 여러 계정에 올리기 | 영상 지문으로 감지돼 전 계정이 위험 |
| 팀원 계정끼리 팔로우·좋아요·댓글 | 인기 조작 네트워크로 판정 |
| 새로 만든 계정에서 바로 링크 홍보 | 스팸 신호. 2주 워밍업 후에 시작 |
| 공개 댓글에 자동 답글 | "봇 계정" 인상 → 회복 불가 |

### 7-3. 문구에서 쓰지 말아야 할 표현

공개 발행물(인스타·유튜브·쓰레드)에서는 아래를 쓰지 않습니다.

- 술, 음주, 취함, 만취 → **"모임", "늦은 밤"** 으로
- 음주 측정, 취기 판별 → **쓰지 않음**
- 안전 보장, 사고 예방 → **"무사히", "집에 가는"** 으로

자세한 이유는 프로젝트 폴더의 `CLAUDE.md` 를 보세요.

## 용어 사전

| 단어 | 쉬운 설명 |
|---|---|
| **API** | 프로그램끼리 대화하는 통로. "사람이 클릭하는 대신 프로그램이 대신 누르는 방법" |
| **토큰 (token)** | 허락증. "이 프로그램이 내 계정에 글을 올려도 됩니다"라는 증명서. **비밀번호처럼 다뤄야 함** |
| **앱 (개발자 앱)** | 메타·구글에 "이런 프로그램을 쓰겠다"고 등록하는 신청서. 실제 앱이 아니라 등록 항목 |
| **역할 / 테스터** | 그 개발자 앱을 쓸 수 있는 사람 목록. 여기 등록돼야 토큰이 나옴 |
| **검수 / 감사 (Review, Audit)** | 플랫폼이 "이 프로그램 써도 되는지" 심사하는 것. 통과 전에는 기능이 제한됨 |
| **프로페셔널 계정** | 인스타의 사업자·크리에이터용 계정. 개인 계정은 API를 못 씀 |
| **클립보드** | 복사한 내용이 잠깐 저장되는 곳. Ctrl+C 하면 여기 들어가고 Ctrl+V 로 꺼냄 |
| **UTF-8** | 한글이 안 깨지게 저장하는 방식. 메모장 저장 시 선택 |
| **bat 파일** | 더블클릭하면 정해진 명령을 실행하는 파일 |
| **보조 모드** | 자동 연결 전, 페이지 열기·문구 복사까지만 대신해주는 모드 |
