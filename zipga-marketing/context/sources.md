## C. 고객 목소리 (VoC)

| 소스 | 무엇을 보나 |
|---|---|
| 앱스토어·구글플레이 리뷰 | 경쟁 앱의 불만·칭찬 원문. **별점 1~2점 리뷰가 가장 값지다** |
| 디시인사이드 / 에펨코리아 / 더쿠 / 블라인드 | 술자리·회식·귀가 관련 실제 대화체 표현 |
| 네이버 지식iN | "술 취한 친구", "만취" 관련 질문 — 사용자가 실제로 겪는 상황 |
| X(트위터), 스레드 | 술자리 직후 실시간 반응 |
| 유튜브 댓글 | 음주 관련 콘텐츠 댓글의 공감 표현 |

수집 원칙: 요약하지 말고 **원문을 그대로 인용**한 뒤 해석을 덧붙인다. 사용자가 쓰는 단어가 곧 마케팅 카피의 재료다.

## 소스 사용 규칙

1. **출처 없는 숫자는 쓰지 않는다.** 시장 규모나 통계를 인용할 땐 반드시 기관명·연도·URL을 붙인다.
2. **원문 표현을 보존한다.** VoC는 번역·윤문하지 말고 그대로 인용하고 따로 해석한다.
3. **접근 실패를 숨기지 않는다.** 특정 소스를 못 읽었으면 리포트에 "확인 실패"로 명시한다. 추측으로 메우지 않는다.
4. **중복을 걷어낸다.** 어제 리포트와 같은 내용은 "변화 없음"으로 한 줄 처리하고, 새로 생긴 것에 지면을 쓴다.
