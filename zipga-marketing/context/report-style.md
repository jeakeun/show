# 리포트 작성 규칙

모든 리서치 결과물이 지켜야 할 공통 규칙. PDF를 만들기 전에 이 문서를 따른다.

---

## 톤

- 학원 팀 프로젝트 발표에 그대로 인용할 수 있는 수준의 문어체. 과장 없이, 근거 중심.
- 마케팅 수사("혁신적인", "게임 체인저")를 쓰지 않는다. 사실과 해석을 분리해서 쓴다.
- 한 문단은 3~4문장을 넘기지 않는다.

## 구조 (매일 리포트)

1. **오늘의 한 줄** — 어제와 달라진 가장 중요한 것 하나. 없으면 "특이 변화 없음"이라고 쓴다.
2. **경쟁 동향** — 표 형식. 변화가 있는 항목만.
3. **시장·규제** — 새로 확인된 통계·뉴스·정책. 각 항목에 출처 URL.
4. **고객 목소리** — 인용문 3~5개 + 해석. 인용문은 원문 그대로.
5. **키워드 관찰** — 새로 발견된 검색어, 수요 변화.
6. **이번 주 팀 액션 제안** — 3개 이내. 실행 가능한 문장으로.
7. **출처 목록** — 이번 리포트에서 참조한 모든 URL.

## 분량

- 데일리 리포트: A4 2~3페이지. 넘어가면 "오늘의 한 줄"과 "액션 제안"만 남기고 나머지를 줄인다.
- 변화가 정말 없는 날은 1페이지로 끝낸다. **분량을 채우려고 내용을 늘리지 않는다.**

## 근거 표기

- 모든 수치·주장 뒤에 대괄호로 출처 번호를 단다: `월간 음주율 54.9% [3]`
- 리포트 마지막 출처 목록에 번호·기관명·발표일·URL을 적는다.
- 확인하지 못한 정보는 `(미확인)` 표시를 붙이거나 아예 빼고, 절대 추정치를 사실처럼 쓰지 않는다.

## PDF 제작

- 한글 폰트가 반드시 필요하다. 시스템에 설치된 한글 폰트(NanumGothic, Noto Sans KR 등)를 확인하고 지정한다. 폰트를 지정하지 않으면 한글이 네모로 깨진다.
- 파일명: `drink-safe-research_YYYY-MM-DD.pdf`
- 표지는 만들지 않는다. 첫 페이지 상단에 제목·날짜·조사 범위 한 줄이면 충분하다.
- 표는 실제 표로 그린다. 텍스트 정렬로 흉내 내지 않는다.
