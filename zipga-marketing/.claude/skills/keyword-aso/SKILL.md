# 키워드 · ASO 리서치

앱스토어와 검색엔진에서 우리 앱이 발견되게 만들 검색어를 찾는다. 이 제품은 카테고리 이름이 아직 정해지지 않은 시장이라, **사용자가 이 문제를 뭐라고 부르는지 찾아내는 것**이 리서치의 절반이다.

## 시작하기 전에

`context/research-profile.md`의 4번(키워드 시드)과 `context/sources.md`의 D 섹션을 읽는다.

## 조사 절차

### 1단계 — 시드 확장

프로필의 키워드 시드를 출발점으로, 자동완성과 연관검색어를 타고 확장한다.

- 네이버 자동완성·연관검색어 (한국어 구어체 표현이 여기서 나온다)
- 구글 자동완성 (질문형 롱테일)
- 앱스토어·플레이스토어 검색창 자동완성 (ASO 후보의 핵심 소스)

각 시드마다 2단계까지 타고 들어간다. `술 취했는지` → `술 취했는지 확인하는 법` → `술 취했는지 테스트`

### 2단계 — 의도 분류

찾은 키워드를 검색 의도로 나눈다. 의도가 다르면 대응하는 콘텐츠도 다르다.

| 의도 | 예시 | 대응 |
|---|---|---|
| 문제 인식 | "친구 만취했을 때" | 블로그·콘텐츠로 유입 |
| 해결책 탐색 | "취기 테스트 앱" | 앱스토어 노출이 직접 작동 |
| 지명 검색 | 경쟁 앱 이름 | 비교 콘텐츠 |
| 게임 수요 | "술게임", "술자리 게임" | **우리의 1순위 유입 경로.** 트래픽이 가장 크고, 앱 성격상 여기가 정면이다 |

### 3단계 — 경쟁 강도 판단

전문 유료 도구 없이 판단해야 하므로 대리 지표를 쓴다.

- 검색 결과 1페이지가 광고·대형 매체로 채워져 있나 (→ 경쟁 높음)
- 앱스토어에서 해당 키워드로 검색했을 때 상위 앱이 그 키워드를 제목에 넣었나 (→ 선점됨)
- 결과가 엉뚱한 것들로 채워져 있나 (→ **기회**. 수요는 있는데 답이 없다는 뜻)

세 번째 유형을 최우선으로 표시한다. 이 시장에서 가장 값진 발견이다.

### 4단계 — 계절성 확인

Google Trends로 연말·연초 스파이크를 확인한다. 회식 시즌 수요 곡선은 출시·마케팅 타이밍의 근거가 된다.

## ASO 권고안 만들기

조사 결과로 아래를 제안한다.

- **앱 이름 + 부제 후보 3안**: 각 안이 어떤 키워드를 겨냥하는지 명시
- **카테고리 선택 권고**: 라이프스타일 / 건강·피트니스 / 소셜 중 어디에 등록할지. 경쟁 앱들이 어디에 있는지를 근거로
- **설명문 첫 3줄 초안**: 검색 노출과 전환에 가장 크게 작용하는 부분

## 판단 규칙

- 검색량 수치를 지어내지 않는다. 정확한 볼륨을 알 수 없으면 "자동완성 상위 노출" 같은 관찰 사실만 적는다.
- 영어 키워드를 한국 시장 우선순위에 섞지 않는다. 별도 섹션으로 분리한다.
- **"음주 측정", "취기 판별", "음주측정기" 계열 키워드는 제외한다.** 하드웨어 수요와 섞일 뿐 아니라, 우리 앱이 음주 상태를 측정한다는 인상을 준다. 앱은 "취함"을 판정하지 않고 게임 점수만 보여주기로 했으므로 이 결정과 어긋난다.
- 대신 **술게임 계열 키워드가 1순위다.** 우리는 측정 앱이 아니라 게임으로 발견되어야 한다. 이쪽이 검색량도 훨씬 크다.

## 출력

`context/report-style.md` 규칙을 따른다. 신규 발견 키워드는 프로필의 시드 목록에 추가할 후보로 따로 표시한다.
