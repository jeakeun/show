# 처음부터 끝까지 따라하기 — 영상 만들어서 3개 채널에 올리기

집가 마케팅 영상 하나를 **만들고 → 가져오고 → 올리는** 전 과정입니다.
익숙해지면 영상 1개당 손 가는 시간은 5분 정도입니다.

> 폴더 위치: `바탕화면\show\zipga-marketing`
> 콘텐츠 기획 15개는 `content\영상기획.md` 에 있습니다. 아래는 1번(01_훅A_연락두절) 기준 예시입니다.

---

## 1단계. ComfyUI에서 영상 만들기 (약 5~10분, 대부분 기다리는 시간)

1. **Comfy Desktop 실행** (이미 켜져 있으면 그대로)
2. 왼쪽 세로 메뉴에서 **"템플릿"** 클릭
3. 템플릿 목록에서 **"MiniMax H3"** 검색 → **Text to Video** (글→영상) 카드 클릭
   - 처음 열 때 "모델 다운로드" 창이 뜨면 다운로드 (이미 받아졌으면 안 뜸)
4. 화면에 상자(노드)들이 나타납니다. 만질 곳은 **딱 두 군데**예요:

   **① 해상도 선택기 (Resolution Selector) 상자**
   - `aspect_ratio` 를 **`9:16 (Portrait Widescreen)`** 으로 변경 ← 세로 영상용, 꼭!

   **② Image to Video (MiniMax H3) 상자의 `prompt` 칸**
   - 원래 있던 영어 글을 전부 지우고,
   - `content\comfyui프롬프트\01_훅A_연락두절.txt` 파일을 메모장으로 열어 내용 전체 복사 → 붙여넣기

5. 화면 위쪽 가운데의 **"실행"** 버튼 클릭
6. 기다리기 — 위쪽에 진행률(%)이 표시됩니다
   - **첫 실행은 모델을 불러오느라 5~15분**, 두 번째부터는 훨씬 빨라요
7. 완성되면 "비디오 저장" 상자에 미리보기가 뜨고, 파일은 자동 저장됩니다 (위치는 신경 안 써도 됨 — 다음 단계가 알아서 찾아요)

> 💡 **같은 프롬프트로 다시 뽑고 싶으면** 그냥 "실행"을 또 누르세요. seed(랜덤값)가 바뀌어 다른 느낌으로 나옵니다. 8개 뽑아서 3개 건지는 게 정상입니다.

---

## 2단계. 가져오기 (10초)

1. `zipga-marketing\uploader` 폴더 열기
2. **`가져오기.bat` 더블클릭**
3. 창에 "가져옴: ○○○.mp4" 라고 뜨면 성공 — `watch` 폴더에 들어와 있습니다

---

## 3단계. 이름 바꾸고 문구 붙이기 (30초)

1. `uploader\watch` 폴더를 열면 방금 가져온 영상이 있습니다
   (이름이 `MiniMax_H3_00001.mp4` 같은 식일 거예요)
2. 이름을 기획 슬러그와 똑같이 변경: **`01_훅A_연락두절.mp4`**
3. `content\문구` 폴더에서 **`01_훅A_연락두절.txt`** 를 복사해서 `watch` 폴더에 붙여넣기

이제 watch 폴더가 이렇게 되어 있으면 준비 끝:
```
watch\
├─ 01_훅A_연락두절.mp4
└─ 01_훅A_연락두절.txt
```

> 💡 나레이션·자막을 얹고 싶으면 이 단계에서 CapCut 같은 편집 앱으로 영상을 다듬은 뒤 watch 에 넣으세요. 나레이션 문구는 기획표(`content\영상기획.md`)에 적혀 있습니다.

---

## 4단계. 올리기 (플랫폼당 30초)

1. **`업로드.bat` 더블클릭**
2. 지금은 "보조 모드"라서 플랫폼마다 이렇게 진행됩니다:
   - 업로드 페이지가 브라우저에 자동으로 열림
   - 문구는 **이미 클립보드에 복사돼 있음**
   - 영상 파일이 탐색기에 **선택된 상태로** 열림
3. 할 일은 두 동작뿐:
   - 탐색기의 영상을 업로드 페이지로 **드래그**
   - 문구 칸에 **Ctrl+V**
4. 올렸으면 검은 창에서 **엔터** → 다음 플랫폼으로 넘어감
5. 세 개 다 끝나면 "이 영상 처리가 끝났나요?" 에 **y** 입력 → 영상이 `uploaded` 폴더로 이동 (중복 방지)

> 💡 유튜브·인스타를 API 로 연결하면 이 단계가 통째로 자동이 됩니다. 연결법은 `uploader\마케팅자동화 설명서.md` 1~3장.

---

## 전체 흐름 한눈에

```
[ComfyUI]                [uploader 폴더]
프롬프트 붙여넣기 → 실행    가져오기.bat → 이름변경+문구복사 → 업로드.bat
     (5~10분)                (10초)         (30초)           (플랫폼당 30초)
```

- **같은 영상 파일을 여러 계정에 올리지 마세요** — 같은 기획이라도 계정마다 "실행"을 새로 눌러 다른 seed 로 뽑은 영상을 쓰세요
