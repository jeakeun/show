# 쓰레드 올리는 법

> **쓰레드는 다른 채널보다 유리한 점이 두 개 있습니다.**
> ① 글 안의 **링크가 눌립니다** (인스타는 안 됨)
> ② API 연결에 **심사가 없습니다** — 오늘 바로 자동화까지 가능

---

## 준비된 글 4개

| 파일 | 성격 | 언제 쓰나 |
|---|---|---|
| `1_메인글.txt` | 서비스 소개 + 링크 | **오늘 첫 글로 이걸** |
| `2_만드는이야기.txt` | 왜 만들었는지 (개인적 이야기) | 이틀 뒤쯤 |
| `3_짧은버전.txt` | 핵심만 | 짧게 올리고 싶을 때 |
| `4_질문형.txt` | 링크 없이 반응만 보기 | 워밍업용 · 댓글 유도 |

전부 **500자 제한 안**에 맞춰져 있습니다 (넘으면 게시가 실패해요).

---

## 방법 A — 손으로 올리기 (지금 바로, 2분)

1. 쓰레드 앱 또는 threads.net 접속
2. 글쓰기 → `1_메인글.txt` 내용 붙여넣기
3. 게시

**프로필도 같이 세팅하세요**
- 소개: 인스타와 같은 문구 (`instagram\2_프로필_소개.txt`)
- 링크: `https://zip-ga-frontend.vercel.app/`

> 쓰레드 계정은 **인스타 계정과 연결**됩니다. 인스타가 있으면 쓰레드는 바로 만들어져요.

---

## 방법 B — API 연결해서 자동화 (20분, 오늘 가능)

한 번 해두면 이후로는 `uploader\3_쓰레드만.bat` 더블클릭이면 끝입니다.

### B-1. 쓰레드 전용 앱 만들기

> ⚠️ **인스타용 앱으로는 안 됩니다.** 쓰레드는 별도 앱이 필요해요.

1. https://developers.facebook.com → **내 앱** → **앱 만들기**
2. 사용 사례에서 **Threads API** 선택 → 다음
3. 앱 이름 `zipga-threads` 입력 → 앱 만들기

### B-2. 권한 추가

앱 대시보드 → Threads 사용 사례 설정 → 권한에서 두 개 추가
- `threads_basic`
- `threads_content_publish`

### B-3. 🔴 내 계정을 테스터로 등록 (여기서 대부분 막힙니다)

1. 왼쪽 메뉴 **앱 역할 → 역할** → **사람 추가** → **쓰레드 테스터**로 본인 계정 초대
2. **수락은 이메일이 아니라 쓰레드 앱 안에서** 합니다:

   **쓰레드 앱 → 설정 → 계정 → 웹사이트 권한 → 초대 수락**

3. 수락 후 **5~10분 기다립니다** (바로 하면 "개발자 역할 권한이 부족합니다" 오류가 납니다)

### B-4. 토큰 발급

앱의 Threads 설정 화면 → **토큰 생성(Generate Access Token)** → 나온 긴 글자 복사

### B-5. 설정에 입력

`uploader\config.json` 을 메모장으로 열어서:

```json
"threads": {
  "enabled": true,
  "threads_user_id": "",
  "access_token": "B-4에서 받은 토큰"
}
```

`threads_user_id` 는 비워두면 프로그램이 자동으로 찾습니다.

### B-6. 테스트

`uploader\watch` 에 올릴 영상과 `영상이름.threads.txt` 를 넣고
**`3_쓰레드만.bat` 더블클릭**

## 알아둘 것

| 항목 | 내용 |
|---|---|
| 글자 수 | **500자 제한** — 넘으면 게시 실패 |
| 영상 | API로는 **영상을 못 올립니다** (공개 URL이 필요해서). 영상은 손으로 올리세요 |
| DM | 쓰레드는 **DM 기능 자체가 없습니다**. 링크는 글 안에 직접 넣으면 됩니다 |
| 한도 | 24시간에 250건 (우리는 주 몇 건이라 여유) |
| 링크 | **눌립니다** — 쓰레드의 가장 큰 장점 |
