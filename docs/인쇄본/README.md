# 인쇄본 (PDF)

포트폴리오 HTML을 **A4 인쇄용으로 다시 조판해서** 뽑은 PDF입니다.
브라우저에서 그냥 `Ctrl + P` 하면 이미지 줄과 섹션이 쪽 경계에서 잘립니다.

| 파일 | 쪽수 | 쓰는 곳 |
|---|---|---|
| `포트폴리오_베일업_영상.pdf` | 6쪽 | 베일업 **AI 영상 프로듀서** 지원 |
| `포트폴리오_베일업_이미지.pdf` | 6쪽 | 베일업 **AI 이미지 프로듀서** 지원 |
| `포트폴리오.pdf` | 4쪽 | 잡코리아 · 원티드 등 일반 지원 |

## 어떻게 만드나

```
python3 tools/포트폴리오_인쇄본.py <포트폴리오.html> <인쇄용.html>
```

그다음 크로미움 헤드리스로 `--no-pdf-header-footer --print-to-pdf` 하면 됩니다.
(`--print-to-pdf-no-header` 는 무시돼서 파일 경로와 날짜가 모든 쪽에 박힙니다.)

인쇄본 조판에서 하는 일

- 다크 테마여도 **인쇄는 항상 밝은 테마**로 (잉크·가독성)
- 이미지 줄(`.shots`)·숫자판(`.nums`)·단계표(`.tt`)·프로젝트 카드(`.pj`)를 **쪽 경계에서 쪼개지 않음**
- 화면용 모바일 2열 규칙이 인쇄에 먹는 문제를 막고 **4열·3열을 다시 강제**
- 머리글 다음 첫 섹션만 같은 쪽에 두고, 그 뒤 큰 섹션은 **새 쪽에서 시작**
- 프로젝트 카드 여백을 줄여 **한 쪽에 두 개**가 들어가게
