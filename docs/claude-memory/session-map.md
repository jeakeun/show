세션은 "한 세션 = 한 목적"으로 나눈다. 사이드바 그룹 2개로 정리(2026-11-20).

- **유튜브 그룹**: "유튜브 (1분호기심·뿅뿅마을·영상 도구)" 세션 — 1분호기심, 뿅뿅마을(kids-toon), 영상 생성·효과음 도구 조사(Seedream 5.5 비교, sfx-kit·earshot 시험)까지 여기서.
- **취업·인턴 그룹**:
  - "취업·서류" 세션 — AX 인재전쟁 프로필, 경기도 일경험 신청서, 지원서 ([[job-applications-2026-11]], [[job-search-rules]]).
  - "인턴 업무" 세션 — 청년후계영농 사회적협동조합 인턴(사내 자동화·웹사이트 유지보수). 출근 후 사이트 종류를 듣고 시작. 작업 흐름은 브랜치 → 자동 검사(처음 4~5개) → 직접 실행 확인 → main → 운영, 실행 증거 없이는 합치지 않는다.

**Why:** 한 세션에 유튜브·취업·서류·조사가 섞여 요약이 반복되며 앞 내용이 흐려짐(사용자 2026-11-20 요청).
**How to apply:** 다른 주제 요청이 오면 해당 그룹 세션으로 가라고 안내하거나 spawn_task로 새 세션 칩을 만든다. 세션 사이 연결은 메모리 파일 + 새 세션 첫 문장 한 줄로 한다. 세션이 끝나면 남은 할 일을 메모리에 적는다.
