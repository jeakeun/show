세션은 "한 세션 = 한 목적"으로 나눈다. 사이드바 그룹 2개로 정리(2026-11-20).

- **유튜브 그룹**: "유튜브 (1분호기심·뿅뿅마을·영상 도구)" 세션 — 1분호기심, 뿅뿅마을(kids-toon), 영상 생성·효과음 도구 조사(Seedream 5.5 비교, sfx-kit·earshot 시험)까지 여기서.
- **취업·인턴 그룹**:
  - "취업·서류" 세션 — AX 인재전쟁 프로필, 경기도 일경험 신청서, 지원서 ([[job-applications-2026-11]], [[job-search-rules]]).
  - "인턴 업무" 세션 — (인턴 회사) 인턴(사내 자동화·웹사이트 유지보수). 회사 사이트 = (회사 사이트 비공개) **큐샵(QUV) 무료 홈페이지 빌더**로 제작(2026-11-21 확인), **첫 출근 2026-11-23(월)**, 11/21에 사이트 둘러보고 손볼 곳 8가지(남은 템플릿 메뉴 큐브식당·/about, 저작권 "LOGO", 어색한 영어 번역, D-Day 00, 빈 달력, 오래된 공지, 큐샵 광고·Powerd 오타, SNS 아이콘 확인) 미리 찾아둠 — 코드 저장소가 아니라 큐샵 관리자 화면에서 편집하는 방식. 사이트 빌더라 브랜치·CI는 해당 없음 → 사이트는 "고치기 전 캡처·백업 → 수정 → 화면 직접 확인(PC·폰) → 변경 기록" 방식. 브랜치 → 자동 검사(처음 4~5개) → 직접 실행 확인 → main 흐름은 따로 만드는 자동화 코드에만 적용. 어느 쪽이든 실행 증거 없이는 끝났다고 하지 않는다.

- **유튜브 그룹 — "숏드라마" 세션**(2026-11-21 추가): AI 웹드라마(show/webdrama, [[webdrama]]) 전용. 1분호기심·뿅뿅마을은 원래 유튜브 세션.
- **공부 그룹**: "공부" 세션(2026-11-21 추가) — 개념 질문, 강의·영상·논문 정리, 학습 노트. 예전 "CNN 학습 정리" 세션도 이 성격.
- 취업·서류 세션이 다루는 프로젝트: jobfit-agent(공고 맞춤 지원서 멀티 에이전트, show/jobfit-agent), 이력서·자기소개서(show/docs/이력서), 지원 기록·채용공고 점검. 주제가 커지면 jobfit-agent 개발은 따로 세션.

**Why:** 한 세션에 유튜브·취업·서류·조사가 섞여 요약이 반복되며 앞 내용이 흐려짐(사용자 2026-11-20 요청).
**How to apply:** 다른 주제 요청이 오면 해당 그룹 세션으로 가라고 안내하거나 spawn_task로 새 세션 칩을 만든다. 세션 사이 연결은 메모리 파일 + 새 세션 첫 문장 한 줄로 한다. 세션이 끝나면 남은 할 일을 메모리에 적는다.
