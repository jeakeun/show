시청자가 바로 아는 생활 상식(자릿수·단위·순서·나라·연도)은 사소해도 틀리면 안 된다.
2026-11-19 사용자 지적: 1분호기심 11/18 대본 "전화번호가 3자리씩 끊긴" — 실제 한국 휴대폰은 010-1234-5678 = 3·4·4자리. 코드 장면도 그대로 따라 그림.

**Why:** 사용자가 "이런 사소한거 안틀리게 잘좀하자"라고 직접 지적. 작은 오류가 채널 신뢰를 깎는다.
**How to apply:** 내가 만드는 화면·글·예시에 숫자·형식이 나오면 실제 형식을 한 번 더 확인한다. 1분호기심은 대본 규칙·검수(차단급)·코드 장면 지시에 반영됨(yt-auto 1d00e85). 다른 채널(뿅뿅마을 등) 대본에도 같은 기준을 적용한다.
