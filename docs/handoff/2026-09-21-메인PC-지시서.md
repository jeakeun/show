## 5. 코드 변경 A — 저녁 계열 비율 생활심리 4 : 우주AI 2 + 계열 오기록 재발 방지 (`src/strategy.py`)
- `evening_plan`: 격일(n%2) 대신 **요일 기준** — 화·금(weekday 1, 4)만 `우주AI`, 나머지 `생활심리`. 우주AI 편도 플레이북대로 '사람 관계' 프레임(프롬프트는 playbook 승인으로 이미 주입됨).
- `pipeline.py` 의 "아침 계열과 중복 금지" 반전 로직은 유지하되, 아침이 `고전실험`이면 반전이 일어나지 않으므로 그대로 둔다.
- `record()`/`normalize_category`: **slot이 classic이고 tag가 아침이면 category를 무조건 `고전실험`으로 기록**(오늘 오기록의 근본 원인 차단).
- 스모크: `python -c "from src import strategy; import datetime; print(strategy.evening_plan())"` 를 실행해 오늘(월) → 생활심리 확인.

## 6. 코드 변경 B — 콤피 클립 A/B를 제대로 다시 (2주 한정) (`config.json` hook_clip + `src/pipeline.py`)
사용자 원칙: 지난 2주는 실패가 아니라 '실험 무효'(대조군이 콤피 실패편이었음). 딱 2주만 제대로 하고, 신호 없으면 폐기.
- 적용 대상: **저녁편 중 계열이 생활심리인 날만** (우주AI 편은 클립 없음 고정 — 계열 효과가 클립 효과를 덮으므로).
- 배정: 날짜 일(day)이 홀수면 클립=Y, 짝수면 N. `hook_clip` 설정에 `"ab_by_day": true` 를 두고 pipeline에서 읽는다.
- 슬롯 기록에 `hook_clip_assigned`(Y/N 배정)와 `hook_clip`(실제 성공) 둘 다 남긴다 — 콤피 실패는 '배정 Y·실패'로 구분.
- 종료 규칙(insights 프롬프트 [실험 중] 블록에 그대로 적기): 배정 Y·N 각 4편(48h 경과) 채워지면 채점, Y 중앙값이 N의 1.3배 미만이면 **클립 실험 종료·hook_clip.enabled=false**. 힉스필드/시드댄스 등 유료 모델 도입은 이 결과가 ✅일 때만 재논의.
- `--no-upload` 테스트로 상태 파일 오염 없이 한 번 돌려 meta에 두 필드가 찍히는지 확인.
