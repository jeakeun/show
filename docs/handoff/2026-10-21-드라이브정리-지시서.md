# 메인 PC 클로드 지시서 — C·D 드라이브 정리 (2026-10-21, 클라우드 세션에서 작성)

사용자가 이 파일을 붙여넣거나 "10/21 드라이브정리 지시서 실행해"라고 하면 아래를 **순서대로** 실행한다.
흐름은 **점검(읽기만) → 정리안 → 주인 승인 → 승인된 것만 삭제 → 다시 점검해 보고**. 승인 전에는 아무것도 지우지 않는다.
배경: 사용자 지시 "C드라이브 D드라이브에 필요 없는 거 정리하자"(2026-10-21). 유니티 MCP로 게임 에이전트를 만들 계획이라
유니티 편집기와 프로젝트를 둘 공간(수십 GB, D 드라이브)도 필요하다.

## 0. 먼저 받기
```
cd C:\Users\User\OneDrive\Desktop\show
git fetch origin
git merge origin/claude/gifted-babbage-aw2t9a     # tools/disk_scan.py + 이 지시서
```

## 1. 시간 확인
예약 작업과 겹치지 않게 한다. 피할 시간: 07:00~07:20, 08:00~08:20, 09:30~09:50, 17:20~18:30, 23:50~00:20,
일요일 09:00·10:00·21:30. 10분 샘플러·코인 사이클은 가벼워서 상관없다.
지금 도는 작업이 없는지 확인: `Get-ScheduledTask | Where-Object State -eq 'Running'`

## 2. 점검 (읽기 전용, 5~20분)
```
py -3 tools\disk_scan.py
```
(또는 `tools\disk-scan.bat` 더블클릭. 관리자 권한으로 돌리면 Windows 임시 폴더 크기까지 정확하다.)
바탕화면에 `드라이브점검-YYYYMMDD-HHMM.md` 가 생긴다. **개인 경로 목록이라 커밋 금지** (show는 공개 저장소).

| 2 | `C:\_moved_to_D_*` (9/4 D 이전 때 남긴 C 원본) | ✅A 아래 4-2 확인 통과 시 삭제 / B 그대로 |
| 3 | `D:\yt-auto\output` 오래된 날짜 폴더 (리포트 3절 월별) | ✅A 최근 30일만 남김 / B 최근 90일 남김 / C 그대로 |

| 5 | 콤피 output 오래된 결과물, 안 쓰는 모델 | 목록을 보여주고 주인이 고름. 17:20 저녁 클립 워크플로가 쓰는 모델은 후보에서 제외 |

## 4. 승인된 것만 삭제

### 4-1. 공통 방법
- 프로그램은 폴더를 지우지 말고 **설정 > 앱**에서 제거한다.
- Windows 임시 파일·업데이트 원본·오류 보고서·DirectX 셰이더 캐시·휴지통·Windows.old 는
  **설정 > 시스템 > 저장소 > 임시 파일**에서 체크해 제거한다. 이때 「다운로드」 체크는 해제한다.
- 캐시: `py -m pip cache purge`, `uv cache clean`, `npm cache clean --force`. 크롬·엣지는 브라우저 설정에서 "캐시된 이미지 및 파일"만.
- 폴더 삭제는 `cmd /c rmdir /s /q "<경로>"` 로 한다. **PowerShell `Remove-Item -Recurse` 는 쓰지 않는다**
  (Windows PowerShell 5.1에서 정션 안쪽 실제 폴더 내용까지 지울 수 있음). 지우기 전 리포트 6절에서 그 경로 아래 링크가 없는지 본다.
- 휴지통 비우기는 맨 마지막에 한다.

### 4-2. `C:\_moved_to_D_<이름>` 삭제 전 확인 (하나라도 실패하면 그 폴더는 남기고 보고)
1. 대응하는 `D:\<이름>` 이 있다.
2. 예약 작업이 C 쪽을 가리키지 않는다. 아래 결과가 비어 있어야 한다.
   ```
   Get-ScheduledTask | ForEach-Object { $t=$_; $t.Actions | ForEach-Object { "$($t.TaskName) | $($_.Execute) $($_.Arguments) $($_.WorkingDirectory)" } } | Select-String -Pattern '_moved_to_D_|C:\\(yt-auto|ai-daily|coin-bot|notify|self-audit)'
   ```
   시작프로그램·바탕화면 바로가기(.lnk) 대상도 같은 기준으로 확인한다.
3. C 원본에만 있고 D에 없는 파일이 없다 (목록만 뽑고 복사하지 않음):
   ```
   robocopy C:\_moved_to_D_<이름> D:\<이름> /L /E /XO /XD .venv __pycache__ output logs /NJH /NJS /NDL /FP
   ```
   여기에 `secrets\`, `.env`, `token*.json` 같은 비밀 파일이 나오면 **삭제하지 말고** 주인에게 보고한다 (내용은 출력 금지).
4. 통과하면 `cmd /c rmdir /s /q "C:\_moved_to_D_<이름>"`.

### 4-3. `D:\yt-auto\output`
날짜 폴더 이름(YYYY-MM-DD)이 승인된 기준일보다 오래된 것만 지운다. 오늘·어제 폴더, `D:\yt-auto\data` 는 절대 건드리지 않는다.

## 5. 다시 점검하고 보고
`py -3 tools\disk_scan.py` 를 다시 돌려 전후 여유 공간을 비교하고 주인에게 보고한다:
드라이브별 전후 여유 공간 표, 항목별 확보 용량, 남겨둔 것과 이유, 실패한 것.
메모리 갱신: youtube-auto-pipeline 메모의 "C 원본은 삭제 안 함" 항목에 삭제 결과와 날짜를 적는다.
메모리 동기화 때 리포트의 경로 목록은 공개 저장소에 올리지 않는다.

## 금지
- 승인 안 된 항목 삭제
- `D:\yt-auto`·`ai-daily`·`coin-bot`·`market-compass`·`hub`·`notify`·`self-audit` 와 그 안의 `secrets`·`.env`·`.venv`
  (승인된 `yt-auto\output` 오래된 날짜 폴더만 예외)
- C에 남은 게임 정션과 D의 실제 게임 폴더, `D:\aivideos`(콤피 설치본), `%USERPROFILE%\.cache\huggingface`(whisper), `%USERPROFILE%\.claude`
- `C:\Windows`, `C:\Program Files*`, `C:\ProgramData` 직접 삭제 (Windows 정리 도구와 설정 > 앱만 사용)
- 점검 리포트 커밋
