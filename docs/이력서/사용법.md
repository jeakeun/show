# 이력서 사용법

`AX_심재근_이력서.html` 은 브라우저에서 열어 그대로 PDF로 내보내는 이력서입니다.

## 1. 채워야 할 곳
노란색으로 표시된 `【 】` 부분만 채우면 됩니다. (개인정보 · 학력 · 자격증)
메모장이 아니라 **VS Code 등 UTF-8 편집기**로 열어서 수정하세요.

## 2. PDF로 내보내기
1. 파일을 더블클릭해 브라우저(크롬/엣지)로 엽니다.
2. `Ctrl + P` → 대상(프린터)을 **"PDF로 저장"** 으로 바꿉니다.
3. 여백은 **기본**, 배경 그래픽 **켜기**(체크)로 두고 저장합니다.
4. 파일명은 `AX_심재근_이력서.pdf` 로 저장합니다.

## 3. 주의
- 이 저장소(`show`)는 **공개 저장소**입니다. 전화번호·생년월일·이메일을 채운 파일은
  절대 커밋하지 마세요. 채운 파일은 로컬(예: 바탕화면)에만 두는 것을 권합니다.
- 링크(GitHub, 유튜브 채널)는 PDF에서도 클릭됩니다. 저장 후 한 번 눌러서 확인하세요.

## 4. 작성 기준
- 레이아웃: 1열(단일 컬럼) — ATS 스캐닝 오류 방지
- 프로젝트: 담당 역할 → 정량 성과 → 트러블슈팅(문제/원인/해결/결과) 구조
- 핵심 키워드와 숫자는 볼드 처리
