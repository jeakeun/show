# 이력서 두 벌 사용법

| 파일 | 어떤 것 | 분량 | 언제 쓰나 |
|---|---|---|---|
| `AX_심재근_이력서.html` | **A안 · 제출용** 흑백 1열, 강조 없음 | A4 3쪽 | **채용 지원 기본.** AI/ATS 자동 검토가 있는 곳, 대기업·공고 접수 |
| `AX_심재근_이력서_디자인.html` | **B안 · 디자인형** 네이비 헤더, 번호 섹션, 태그, 타임라인 | A4 4쪽 | 포트폴리오 첨부, 사람이 직접 보는 자리, 스타트업·소규모 팀 |

내용(경력·프로젝트·교육)은 **두 벌이 완전히 같습니다.** 보이는 방식만 다릅니다.

## 공통 작업

1. 노란색 `【 】`(개인정보)를 채웁니다. 메모장 말고 **VS Code** 등 UTF-8 편집기로 여세요.
2. 파일을 더블클릭해 브라우저로 열고, 오른쪽 위 **「사진 넣기」** 로 증명사진을 고릅니다.
3. `Ctrl + P` → 대상을 **"PDF로 저장"**

### 인쇄 설정

| 항목 | A안 | B안 |
|---|---|---|
| 여백 | **기본** | **없음** (헤더 색이 끝까지 차도록) |
| 배경 그래픽 | 체크 | **체크 (필수)** |

## 주의

- 이 저장소(`show`)는 **공개 저장소**입니다. 개인정보를 채운 파일은 커밋하지 마세요.
- B안은 색과 배경을 쓰기 때문에 **흑백 프린터로 출력하면 헤더가 어둡게 뭉갭니다.** 종이로 낼 땐 A안을 쓰세요.
- 분량이 늘면 A안은 4쪽, B안은 5쪽으로 넘어갑니다. 작성 가이드가 5쪽 이상을 지양하므로 그 선을 넘기지 마세요.

## 작성 기준 (두 벌 공통)

- 프로젝트: 담당 역할 → 정량 성과 → 문제 해결(원인/해결) 구조
- 링크는 헤더에 GitHub 프로필 하나, 나머지는 각 프로젝트 옆에만
- PDF는 텍스트가 그대로 추출되는 상태로 유지 (이미지로 굽지 않기)
