# 이력서 사용법

`AX_심재근_이력서.html` 이 원본입니다. 개인정보(생년월일·연락처·이메일·주소·고등학교)는
공개 저장소에 올리지 않으려고 노란색 `【 】` 플레이스홀더로 비워 두었습니다.

## 1. 채우기
노란색 `【 】` 부분만 채웁니다. **메모장이 아니라 VS Code** 등 UTF-8 편집기로 여세요.

## 2. PDF로 내보내기
1. 파일을 더블클릭해 브라우저(크롬/엣지)로 엽니다.
2. `Ctrl + P` → 대상(프린터)을 **"PDF로 저장"** 으로 바꿉니다.
3. 여백은 **기본**, 배경 그래픽 **켜기**(체크)로 두고 저장합니다.
4. 파일명은 `AX_심재근_이력서.pdf` 로 저장합니다.

## 3. 주의
- 이 저장소(`show`)는 **공개 저장소**입니다. 개인정보를 채운 파일은 커밋하지 마세요.
- 링크(GitHub, 유튜브 채널)는 PDF에서도 클릭됩니다. 저장 후 한 번 눌러서 확인하세요.
- 분량은 **A4 4페이지**에 맞춰져 있습니다. 내용을 추가하면 5페이지로 넘어갈 수 있는데,
  작성 가이드가 5페이지 이상을 지양하라고 하므로 4페이지를 유지하세요.

## 4. 작성 기준
- 레이아웃: 1열(단일 컬럼) — ATS 스캐닝 오류 방지
- 프로젝트: 담당 역할 → 정량 성과 → 트러블슈팅(문제/원인/해결/결과) 구조
- 핵심 키워드와 숫자는 볼드 처리
