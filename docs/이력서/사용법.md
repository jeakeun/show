## 공통 작업

1. 노란색 `【 】`(개인정보)를 채웁니다. 메모장 말고 **VS Code** 등 UTF-8 편집기로 여세요.
2. 파일을 더블클릭해 브라우저로 열고 **「사진 넣기」** 버튼으로 증명사진을 고릅니다.
3. `Ctrl + P` → 대상 **"PDF로 저장"** → 여백 **기본**, 배경 그래픽 **체크**
