핵심 요약은 유튜브 콘텐츠 자동화와 마케팅 자동화 에이전트를 맨 앞에 두었고,
프로젝트에 `market-compass`를 추가했습니다.

## 공통 작업

1. 노란색 `【 】`(개인정보)를 채웁니다. 메모장 말고 **VS Code** 등 UTF-8 편집기로 여세요.
2. 파일을 더블클릭해 브라우저로 열고 **「사진 넣기」** 버튼으로 증명사진을 고릅니다.
3. `Ctrl + P` → 대상 **"PDF로 저장"** → 여백 **기본**, 배경 그래픽 **체크**

## 아직 비어 있는 칸

  새움소프트가 물은 "공백기"가 이 구간일 가능성이 큽니다. 무엇을 하셨는지 알려주시면 넣겠습니다.
- **nudy 기간** (B안) — 현재 `2026.09 – 진행 중`으로 적어뒀습니다. 실제 시작월을 확인해 고치세요.

## 주의

- 이 저장소(`show`)는 **공개 저장소**입니다. 개인정보를 채운 파일은 커밋하지 마세요.
  저장소 안의 두 HTML은 생년월일·연락처·이메일·주소·고등학교명을 전부 `【 】`로 비워 둔 상태입니다.
- 내용을 더 넣으면 두 벌 다 5쪽으로 넘어갑니다.
  작성 가이드가 5쪽 이상을 지양하므로 그 선을 넘기지 마세요.
- PDF는 텍스트가 그대로 추출되는 상태를 유지하세요(이미지로 굽지 않기).
  AI·ATS 검토가 있는 곳에서 글자를 못 읽으면 내용과 무관하게 걸러집니다.

## 작성 기준 (두 벌 공통)

- 프로젝트: 담당 역할 → 정량 성과 → 문제 해결(원인 → 해결) 구조
- 링크는 헤더에 GitHub 프로필 하나, 나머지는 각 프로젝트 옆에만
- 강조는 제목·라벨 등 구조를 나타내는 곳에만
- 한 프로젝트나 한 섹션이 페이지를 넘어가지 않도록 쪽 경계를 맞춰 둠 (강민초 님 피드백 반영)
