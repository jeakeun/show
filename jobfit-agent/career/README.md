# 경력 문서 (검색 대상)

근거 검색가가 찾는 문서입니다. **공개해도 되는 내용만** 둡니다. 개인정보가 있는 문서는 `private/` 에 둡니다(깃 제외).

지금 쓰는 문서 (`jobfit/config.py` 의 `DEFAULT_SOURCES`, 2-2 단계에서 확정 2026-10-27):
- 운영: 프로젝트 개요 (show 저장소 `README.md`), 운영 자동화의 설계 결정 기록 (`docs/멀티에이전트/02-내-설계결정-기록.md`)
- 학습: 학습 기록 (`docs/멀티에이전트/03~05`)

근거가 아닌 부분은 뺍니다 (`SOURCE_RULES`, `DROP_LINES`). 폴더 지도, "아직 약한 곳"(없는 경험 목록),
개발 중인 프로젝트(market-compass·웹드라마·jobfit-agent 자신)는 운영 근거로 치지 않습니다. 이유는 [DESIGN.md](../docs/DESIGN.md) J-16.

문서마다 **직접 운영한 경험인지, 학습으로 해본 것인지**를 구분해 표시합니다. 검증가가 "학습으로 해본 것"을 "실무 경험"처럼 쓴 문장을 잡아내는 데 씁니다.
