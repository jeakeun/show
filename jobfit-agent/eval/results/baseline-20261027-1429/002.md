## 자기소개서

저는 개인 자동화 프로젝트들을 클로드 코드와 함께 만들어, 메인 PC의 윈도우 작업 스케줄러에서 매일 자동으로 운영하고 있습니다 [E1]. 운영하면서 숫자가 틀리는 사고를 여러 번 겪었습니다 [E32, E33]. 유튜브 회고는 추적 중인 영상 50편의 합으로 일별 조회수를 계산했습니다 [E32]. 그런데 옛 영상이 목록에서 밀리면서 숫자가 떨어지는 착시가 생겼고, 회고 AI는 이 숫자로 "-76% 급락"이라는 원인 서사까지 지어냈습니다 [E32]. 취업 정보 수집기의 "연속 0건" 카운터도 실제 9일보다 많은 12일로 부풀려져 있었습니다 [E33]. 이후 계산과 누적 상태, 정해진 형식의 문자열은 코드가 맡고, 해석과 문장은 AI가 맡도록 경계를 정했습니다 [E33]. 회차별 실측 기록을 남겨 코드가 계산하게 바꾸었고, 그 결과 계산 근거가 파일로 남아 감사할 수 있게 됐습니다 [E33, E34].

가상 자금 1,000만 원으로 매매 전략을 검증하는 코인 모의투자 봇에는 손절 -2%, 1회 10%, 하루 -3% 한도, `STOP.txt` 신규매수 중지 같은 안전장치를 코드로 넣었습니다 [E14]. 읽기 전용 감사 에이전트로 리포트를 원본 데이터와 대조해, 코인봇의 수수료 계산 오류(20.5%)와 노출된 API 키를 찾아냈습니다 [E37]. 이후 감사에서는 손절 15건이 모두 -2%를 넘겨 평균 -2.94%에 체결됐다는 사실도 드러났습니다 [E38]. AI 출력 문구로 성공을 판정하다 오판한 일이 반복된 뒤에는, 결과물 파일 실존과 종료 코드로 판정하도록 바꿨습니다 [E43]. 자동화 실패와 품질 저하 발행은 바탕화면 경고 파일과 폰 푸시로 알리게 했습니다 [E43, E44]. 비용을 줄이려고 출력 한도를 낮췄다가 회고 본문이 0자로 실패한 적이 있습니다 [E41]. 그 뒤로 한도 초과를 명시적 오류로 처리하고, 실패하면 폰으로 알리도록 고쳤습니다 [E42].

Java·Spring Boot·React·AWS는 7개월 과정에서 익혔습니다 [E103]. 레거시 시스템 연계를 학습하면서, 정해진 쿼리에 파라미터만 받는 읽기 도구를 예제로 만들어 실행해 보았습니다 [E99]. 함께 만든 쓰기 도구는 사람 승인 전에는 DB 값이 바뀌지 않는다는 것도 확인했습니다 [E99, E100, E101]. 판정이 매번 같아야 하는 규칙은 코드로 둔다는 원칙에 따라, 카카오 마케팅 메시지 에이전트의 규제 검사를 테스트가 붙은 규칙 R01~R12로 개발하고 있습니다 [E15, E45]. 2일차 기준으로 Guard 테스트 24/48을 통과했습니다 [E15, E45]. 설계 결정은 상황·대안·결정·이유·대가·결과 순서로 10개를 기록해, 근거를 설명할 수 있게 정리해 두었습니다 [E21]. 이 시스템들은 제가 설계하고 운영했으며, 구현은 AI 코딩 도구와 함께 했습니다 [E49].

## 이력서 강조

- 숫자와 누적 상태는 코드가 계산하도록 AI와 코드의 경계를 정했습니다. 부풀려진 카운터(12일, 실제 9일)는 회차별 실측 기록을 바탕으로 코드가 계산하도록 전환했습니다 [E33, E34].
- 읽기 전용 감사로 코인 모의투자 봇의 수수료 계산 오류(20.5%)와 노출된 API 키를 발견했습니다. 1회차 주간 감사 시험에서는 8건을 찾아 검증 후 6건을 고쳤습니다 [E37, E38].
- 가상 자금 1,000만 원으로 도는 코인 모의투자 봇에 손절·익절·트레일링·1회 10%·하루 -3% 한도·BTC 급락 가드를 코드로 넣었고, 실제 주문은 넣지 않습니다 [E14].
- 성공 판정 기준을 AI 출력 문구에서 결과물 파일 실존과 종료 코드로 바꿨습니다. 실패와 품질 저하 발행은 폰 푸시로 알리며, 알림이 실패해도 본 작업은 멈추지 않습니다 [E43, E44].
- 분석 AI가 설정 파일을 바꾸면 해시 백업으로 자동 원복하고, 새로 생긴 파일은 격리하는 가드를 넣었습니다. 9/6에 실제로 임시 스크립트를 격리하며 작동을 확인했습니다 [E29, E30].
- Java·Spring Boot·React·AWS를 7개월 과정에서 익혔습니다 [E103]. 정해진 쿼리 기반 읽기 도구와 승인 뒤에만 실행되는 쓰기 도구를 LangChain 예제로 실험했습니다 [E99, E101].
