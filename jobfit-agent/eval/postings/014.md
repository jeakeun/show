About the Role
AX Engineer는 뉴셀렉트의 콘텐츠·크리에이터·커머스 업무를 사람과 AI가 함께 일하는 AI Product로 만드는 사람입니다.
현업의 업무 흐름을 분석해 사람의 판단이 필요한 지점과 AI가 실행할 지점을 구분하고, 실제 업무에 사용되는 Product와 Agent를 설계·개발·배포합니다.
코드를 잘 짜는 것에서 멈추지 않고, 비즈니스 문제를 이해해 실제 사용과 성과로 연결하는 엔지니어를 찾습니다.
현업과 AI의 협업이 자연스럽게 이어지는 프로덕트 구조와 Agent 운영 기반을 만들고, 사용 데이터와 피드백을 반영해 지속적으로 고도화하는 일입니다.

주요업무
1. AI와 사람이 협업하는 AI Product 개발
- 콘텐츠, 크리에이터, 커머스 영역의 업무 흐름을 분석해 AI Product로 구현하고 고도화합니다
- 사람의 판단이 필요한 지점과 AI가 실행할 지점을 구분해, 협업이 자연스럽게 일어나는 프로덕트 구조를 설계하고 개발합니다
2. AI Agent 개발 및 배포
- 현업과 직접 문제를 정의하고, 실제 업무에 사용되는 Agent를 개발·배포합니다
- 배포 이후 사용 데이터와 현업 피드백을 반영해 품질과 활용도를 개선합니다
3. AI Agent 운영 플랫폼 아키텍처 설계·구축
- AI Agent가 안전하게 운영될 수 있는 플랫폼 아키텍처를 설계하고 구축합니다
- 보안, 인증, 데이터 파이프라인 전반의 구조를 설계합니다
4. Agent Harness·품질 체계와 자산화
- Agent가 맥락을 유지하며 안정적으로 일할 수 있도록 컨텍스트 구조와 실행 환경을 설계하고, 테스트·CI/CD 등 품질 체계를 만듭니다
- 공통 로직·프롬프트·로그 구조를 표준화하고, 현업의 프로토타입 수준 산출물을 프로덕션 수준으로 고도화합니다

자격요건
- 소프트웨어 엔지니어링 경력 3년 이상 — AI Agent 또는 LLM 기반 서비스를 직접 설계·개발·배포해본 분
- Python 백엔드와 LLM API 실무 경험이 있고, Agent Framework 활용 또는 자체 Harness를 설계해본 분
- 현업의 업무 흐름을 분석해 AI Product 또는 Agent의 요구사항과 프로덕트 구조로 전환해본 분
- 프로토타입을 실제 사용자가 활용하는 프로덕션 수준의 시스템으로 고도화하고 운영해본 분
- Claude Code, Codex 등 AI 코딩 도구로 본인의 생산성을 이미 높이고 있는 분
- AWS, GCP 등 클라우드 환경 운영 경험

우대사항
- 작은 규모라도 AI Agent를 직접 만들어 현업에 배포·운영해본 경험
- 사람의 판단과 AI의 실행이 함께 작동하는 Human-in-the-loop Product를 설계·개발해본 경험
- 비즈니스 문제를 이해하고, 아키텍처 의사결정을 직접 내려본 분
- Meta, Google, TikTok API 등 광고·마케팅 데이터 자동화 경험이 있으신 분
- 현업의 업무 프로세스를 이해하고 기술 구조로 전환해본 경험
