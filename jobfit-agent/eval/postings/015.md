회사 소개
에이엑스(AX)는 A급 직원의 업무 DNA를 AI로 복제해, 모든 기업이 AI-Native하게 일하도록 만드는 AI 에이전트 전문기업입니다.
AI 직원을 만들고(AWorker), AI 팀을 구성하고(ATeam), AI 조직을 운영하고(ACompany), AI와 일하는 역량을 키우는(AX Campus) end-to-end 솔루션을 제공합니다.
고객사 맞춤 AI 시스템을 구축하면서 동시에 자체 플랫폼의 에이전트 자산이 축적되는 선순환(Flywheel) 구조로 성장하고 있습니다.

주요 업무
AX 자체 솔루션(AWorker, ATeam, ACompany)의 핵심 엔진과 고객사별 맞춤 AI 에이전트 시스템의 백엔드·데이터 파이프라인을 개발합니다. 에이전트가 실제로 기업의 업무 시스템을 조작하고, 데이터를 구조화하고, 멀티에이전트 팀으로 협업할 수 있도록 만드는 역할입니다.
- AX 솔루션 핵심 엔진(NAGE, ECOE, AMAO, K-MCP) 개발 참여
- 고객사 맞춤 AI 에이전트 백엔드 개발 — 에이전트 실행 엔진, 워크플로우 오케스트레이션, 도구 연동
- 기업 데이터 파이프라인 구축 — 비정형 데이터(PDF, 한글, 스캔본) 파싱, 구조화, 온톨로지 구축
- K-MCP 기반 국내 시스템 연동 — 더존, 카카오워크, 나라장터 등 78종+ MCP 어댑터 개발·유지
- RAG 파이프라인 설계 및 최적화
- 외주 개발 파트너와의 기술 협업 — 아키텍처 가이드, 코드 리뷰, 품질 관리

자격요건
- 경력 5년 이상 (공고 머리말)
- Python 또는 Node.js 백엔드 개발 경험 3년 이상
- LLM/AI API 활용 개발 경험 (OpenAI, Anthropic, 오픈소스 모델 등)
- REST API 설계 및 개발
- 데이터 처리 — ETL/ELT 파이프라인, SQL, 비정형 데이터 처리
- 클라우드 인프라 운영 경험 (AWS 또는 GCP)

우대사항
- AI 에이전트 프레임워크 경험 — LangChain, LangGraph, CrewAI, AutoGen 등
- MCP(Model Context Protocol) 개발 경험 또는 이해
- Python + Node.js 모두 활용 가능한 분
- 워크플로우 자동화 — n8n, Activepieces 등
- RAG 최적화 — 벡터DB, 임베딩, 리랭킹, 청킹 전략
- 지식그래프 / 온톨로지 구축 경험
- 한국 기업 시스템(ERP, 그룹웨어, 공공 API) 연동 경험

이런 분을 환영합니다
- AI 에이전트를 직접 만들어본 경험이 있는 사람 (사이드 프로젝트 포함)
- 새로운 AI 프레임워크가 나오면 바로 써보고 장단점을 정리하는 사람
- "이 반복 업무, 에이전트로 자동화할 수 있겠는데"가 본능적으로 떠오르는 사람
