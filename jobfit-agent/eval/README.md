# 평가셋 (2-1 단계)

멀티 에이전트가 정말 나은지는 **같은 문제로 잰 숫자**로만 말할 수 있어서, 코드보다 평가셋을 먼저 만듭니다.

## 구성

| 폴더 | 내용 |
|---|---|
| `postings/NNN.md` | 공고 원문 (회사명이 없어도 됨) |
| `answers/NNN.json` | 사람이 만든 정답: 요구 항목 목록, 채점에서 뺀 항목과 이유, 항목별 정답 근거(2-2에서 채움) |

## 정답을 만드는 규칙

- 요구 항목은 **담당 / 필수 / 우대 / 스킬**로 나눕니다.
- 같은 요구가 여러 곳에 나오면 하나로 합치고, `excluded` 에 이유를 적습니다.
- "기타 업무"처럼 구체적인 요구가 없는 줄은 채점에서 빼고 이유를 적습니다.
- 정답 근거는 `career/` 문서의 위치(파일 + 섹션)로 적습니다. 근거가 없으면 "없음"이 정답입니다. **없는 경력을 있다고 하지 않는 것도 채점 대상**입니다.

## 잴 것

| 단계 | 지표 |
|---|---|
| 공고 분석 | 요구 항목을 빠뜨리지 않았나(재현율), 없는 항목을 만들지 않았나(정밀도) |
| 근거 검색 | 항목별 정답 근거가 상위 k개 안에 들어온 비율 |
| 초안 | 근거 번호가 없는 주장 문장 수, 근거와 안 맞는 문장 수(사람 표본 검사), 과장 동사 수 |
| 운영 | 공고 1개당 비용, 걸린 시간 |

같은 평가셋으로 **에이전트 1개짜리 기준선**과 멀티 에이전트를 비교합니다.

## 현재

- 공고 7개. 목표는 10~20개.
  - `001`: 사용자가 공유한 LangChain AI Agent 개발 공고
  - `002~007`: 멘토 영상(2026-10-26 정리)에 나온 원티드 공고. 클래스101, 채널톡, 아정당, 라프텔, 숲, 에이아이트릭스
- `002~007` 정답표에는 `mentor_reading` 칸이 있습니다. 멘토가 해석한 "회사가 돈 버는 방식 → 중요 지표 → 내세울 증거"를 적었고, 공고 분석가 개선 평가에 씁니다. 해석이 없는 공고는 비워 두고 이유를 적었습니다. 정리 문서는 [멘토-공고읽는법-2026-10-26.md](../../docs/멀티에이전트/멘토-공고읽는법-2026-10-26.md)입니다.
- 채널톡(`003`)은 직군 트랙이 여럿이라 Backend 트랙 기준으로 정답을 만들었습니다.
- `003·004·006` 의 `mentor_reading` 에는 `company_type` 라벨이 있습니다. 멘토 발언을 보고 클로드가 분석가와 같은 분류로 붙였고, 회사 유형 채점에 씁니다.

## 채점 도구

```
python eval_analyzer.py --dry-run   # 가짜 분석가로 채점 흐름 확인 (비용 없음, 저장 안 함)
python eval_analyzer.py             # 실제 분석가 채점 (API 키 필요). 결과는 eval/results/ 에 저장
```

| 기준선 | 요구 항목 재현율 | 정밀도 | 회사 유형 일치 |
|---|---|---|---|
| 가짜 분석가 (공고 줄을 자르기만 함, 10-26) | 86% | 75% | 0/3 |

## 근거 검색 채점 (2-2, 2026-10-27)

정답 요구 항목마다 검색가와 적합도 계산만 돌려 정답 근거(`evidence.json`)와 비교합니다. **모델을 부르지 않아 비용이 없습니다.**
공고 분석가의 흔들림과 섞이지 않게, 분석가가 뽑은 항목이 아니라 정답 항목을 씁니다.

```
python eval_retrieval.py            # 검색 방식을 하나씩 켜 보며 비교. 결과는 eval/results/retrieval-날짜.md
```

- `evidence.json`: 항목마다 정답 판정(운영/학습/없음)과 근거 위치("문서#절"). 클로드가 검색 결과를 보기 전에 붙였고, **사람 확인이 필요합니다** (note 가 있는 항목부터).
- 잰 것: 운영 근거 적중, 학습 근거 적중, 판정 일치, 부풀림(그중 가짜 운영), 깎임, 조각 수, 적합도 차이. 설명은 `jobfit/retrieval_eval.py` 맨 위.
- 결과 요약은 [docs/DESIGN.md](../docs/DESIGN.md) J-16.
