순서
  1. 힉스필드(higgsfield.ai) → Video → 모델 Kling 3.0 → Unlimited(무제한) 스위치가 있으면 켜기 (안 켜면 크레딧이 깎입니다)
  2. 화면 비율 9:16, 화질 720p, 길이는 장면마다 적힌 초로 맞추기
  3. 장면 옆의 인물 사진을 참고 이미지(캐릭터·Elements 등)로 넣고 → 「프롬프트 복사」 → 붙여넣기 → 생성
  4. 마음에 들면 다운로드. 1번 장면부터 순서대로 받으세요. 이상하면 다시 생성
  5. 다 받았으면 2_영상가져오기.bat → 3_편집하기.bat

중간에 한 장면만 다시 받았을 때: 2_영상가져오기.bat 대신 명령창에서 python drama.py collect --shot 3

줄거리
첫 출근날 윤서연(한서연)은 선임 비서 차유나가 몰래 뚜껑을 풀어 둔 커피를 들고 가다 엘리베이터에서 나온 팀장 강도현의 셔츠에 쏟는다. 도현은 계약직이라는 소개에 '실수 한 번이면 끝'이라고 경고하지만, 곧바로 엘리베이터 거울로 유나의 고의를 봤다고 밝히며 유나에게 팀 전체 커피 심부름을 시킨다. 서연은 몰래 엄마와 통화하며 태일 장남과의 맞선을 거부하고 그가 분명 재수 없을 거라 말하는데, 바로 뒤에 그 장남인 도현이 서 있다.
보상: 사이다: 서연을 모함하던 유나에게 도현이 '뚜껑 푸는 거 거울로 다 보였다'며 고의를 폭로하고 팀 전체 커피를 다시 사 오게 함
끝 5초 떡밥: 서연이 '태일 장남은 분명 재수 없는 남자일 거야'라고 말하는 순간, 바로 뒤에서 도현이 '누가 재수 없다고요?'라고 묻는다.
