# 몽글이 버추얼 스트리머 사용설명서 🐱

주황 고양이 캐릭터 **몽글이**가 웹캠으로 내 얼굴과 손을 따라 움직여요.
캠 앞에서 사라지면 몽글이가 눈 감고 꾸벅꾸벅 졸면서 "자리비움" 팻말을 들어요.

---

## 1. 실행하기

1. `vtuber` 폴더 안의 **`몽글이 시작.bat`** 을 더블클릭
2. 검은 창이 뜨고, 브라우저가 자동으로 열려요 (검은 창은 끄지 마세요!)
3. 브라우저에서 **카메라 권한 허용**을 눌러주세요
4. 처음 한 번은 AI 모델 다운로드 때문에 10~30초 걸릴 수 있어요 (인터넷 필요)

## 2. 몽글이가 하는 것들

| 내 행동 | 몽글이 반응 |
|---|---|
| 고개 돌리기/기울이기 | 같이 고개 움직임 |
| 눈 깜빡임 | 같이 깜빡임 |
| 말하기 (입 벌림) | 입이 벌어지고 혀가 보임 |
| 웃기 | 입이 커지고 볼이 빨개짐 |
| 눈썹 올리기 | 눈썹 올라감 (놀란 표정) |
| 손 들기/흔들기 | 팔을 들어 따라 움직임 (젤리 발바닥!) |
| **캠에서 사라지기 (2.5초)** | **눈 감고 취침 + Zzz + 잠방울 + "자리비움" 팻말** |
| 다시 나타나기 | "!" 하고 깜짝 놀라며 깨어남 |

## 3. 단축키

- **H** : UI(버튼) 숨기기/보이기 — 방송 전에 꼭 숨기세요! (마우스 가만히 두면 4초 뒤 자동으로 숨겨져요)
- **P** : 트래킹 보기 켜기/끄기 — 얼굴이 점(초록)·손이 점(주황)으로만 표시돼요. **실제 캠 영상은 절대 안 나옵니다**
- **1~4** : 배경색 바꾸기 (1=초록, 2=파랑, 3=마젠타, 4=어두운색)

## 내 얼굴이 나올 걱정은 안 해도 돼요 🔒

- 이 프로그램은 **실제 캠 영상을 화면에 표시하는 기능 자체가 없어요.** 어떤 버튼을 눌러도 얼굴이 나오지 않습니다.
- 캠 영상은 얼굴 위치 계산에만 쓰이고, **내 컴퓨터 안에서만 처리**돼요. 인터넷으로 전송되지 않습니다.
- 단, OBS 쪽에서 주의할 것 2가지:
  1. 소스는 꼭 **"윈도우 캡처"로 몽글이 창만** 선택하세요. "디스플레이 캡처(전체 화면)"를 쓰면 다른 창이 같이 나갈 수 있어요.
  2. 폰을 웹캠으로 쓸 때 **폰 화면에는 캠 영상이 보일 수 있으니**, 폰 화면이 방송 카메라에 비치지 않게만 하면 돼요.

## 4. OBS로 방송에 띄우기 (크로마키)

OBS가 없다면 https://obsproject.com 에서 무료 다운로드하세요.

1. OBS에서 **소스 → + → 윈도우 캡처** → 몽글이 브라우저 창 선택
2. 방금 만든 소스 **우클릭 → 필터 → 효과 필터 + → 크로마 키**
3. 키 색상 형식: **녹색** (기본값) → 초록 배경이 사라지고 몽글이만 남아요!
4. 몽글이를 원하는 위치/크기로 드래그해서 배치
5. 게임 화면이나 다른 소스 위에 올리면 끝!

> 팁: 크로마키가 지저분하면 "유사성" 수치를 조금씩 올려보세요.
> 몽글이 몸에 초록색이 없어서 깔끔하게 빠져요.

## 5. 숲(SOOP) / 치지직 송출

### 치지직
1. 치지직 스튜디오 (studio.chzzk.naver.com) → 방송 관리 → **스트림 키 복사**
2. OBS → 설정 → 방송 → 서비스: **사용자 지정** → 서버: `rtmp://global-rtmp.lip2.navercorp.com:8080/relay` → 스트림 키 붙여넣기
3. OBS에서 **방송 시작**

### 숲 (SOOP, 구 아프리카TV)
1. SOOP 방송국 → 방송설정에서 **스트림 키 확인**
2. OBS → 설정 → 방송 → 서비스 목록에서 **SOOP** 선택 (없으면 "모두 표시" 체크) → 스트림 키 입력
3. OBS에서 **방송 시작**

> 서버 주소는 바뀔 수 있으니, 각 플랫폼 스튜디오 페이지에 나오는 최신 주소를 쓰는 게 가장 정확해요.

## 6. 문제 해결

- **캐릭터가 안 움직여요** → 조명을 밝게, 얼굴이 캠에 잘 보이게 해주세요. P 키로 캠 미리보기를 켜서 확인.
- **에러 화면이 나와요** → 인터넷 연결 확인, 줌/디스코드 등 캠 쓰는 다른 프로그램 종료.
- **캐릭터 모습만 보고 싶어요** → 브라우저 주소 뒤에 `?demo=1` 붙이기 (카메라 없이 실행)
- **부드럽지 않고 뚝뚝 끊겨요** → 다른 무거운 프로그램을 끄고, 브라우저 창을 너무 크게 하지 마세요.
